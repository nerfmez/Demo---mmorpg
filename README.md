# Azure Coast — เมืองท่าเริ่มต้น (ฉบับทดลอง)

เดโมเกมแนว **Anime top-down MMORPG + Buildcraft** เล่นบนเว็บได้ทั้ง PC และ iPad/มือถือ
สร้างด้วย **Three.js** โดยแยก "กฎของเกม" และ "ข้อมูลเกม" ออกจากส่วนแสดงผล เพื่อพร้อมย้ายไป **Godot** ในอนาคต

เอกสารออกแบบต้นฉบับ: [`docs/DESIGN-SUMMARY-TH.txt`](docs/DESIGN-SUMMARY-TH.txt) ·
สถานะเทียบกับดีไซน์: [`docs/DESIGN-STATUS.md`](docs/DESIGN-STATUS.md) ·
คู่มือย้ายไป Godot: [`docs/GODOT-PORT.md`](docs/GODOT-PORT.md)

## ใน Demo มีอะไร

- **หน้าแรก + สร้างตัวละคร:** ตั้งชื่อ เลือกแนวเริ่มต้น (ดาบ / ธนู / เวท — เปลี่ยนทีหลังได้หมด ไม่ต้องเลือก Job) เลือกทรงผม สีผม สีผิว สีตา ผ้าพันคอ เสื้อ ดูตัวละครจริงแบบ 3D ก่อนเริ่ม
- **เซฟ 3 ช่อง + ความคืบหน้า:** เซฟอัตโนมัติ (ตำแหน่ง ของ เควส หินวาร์ป เวลาเล่น) · เล่นต่อจากหน้าแรก · คัดลอก/นำเข้าโค้ดเซฟเพื่อย้ายเครื่อง · เซฟจาก Demo แรกย้ายเข้าช่อง 1 ให้เอง
- **แมพเริ่มต้น 320×240 ม.:** บกราว 80% เริ่มบนหาดผู้มาเยือน เดินตามถนนปลอดภัยเข้าเมืองท่าสีคราม แล้วออกสู่ทุ่ง สวน ป่าโปร่ง และแหลมประภาคาร · ท่าเรือมีทางลาดเดินได้ เรือและประภาคาร · ยังไม่สร้างทั้งทวีป และผังนี้ปรับได้หลังดูภาพจริง
- **หินวาร์ป 5 จุด:** เดินแตะเพื่อปลดล็อก วาร์ปจากแผนที่ (M) ตายแล้วฟื้นที่หินใกล้สุด
- **ภารกิจ:** เนื้อเรื่องหลัก 7 ขั้นในพื้นที่เริ่มต้น + ภารกิจรอง 6 อัน · ติดตามมุมขวาบนและดาวทองบนมินิแมพ
- **มอน 8 ชนิดในแมพเริ่มต้น** ปู สไลม์เกลือ นกนางนวล ปูเสฉวน หมูป่า ด้วง เห็ด และหมาป่า · มอนมีท่าตั้งโจมตีให้อ่านก่อนหลบ
  - หมูป่า: ตั้งท่าก่อนพุ่ง ถ้าพุ่งชนหินจะมึน · ด้วง: หดกระดองแล้วพ่นพิษ
  - หมาป่าหลังหนาม: ล้อมเป็นฝูง กระโจน หอนเพิ่มความเร็ว · เห็ดสปอร์: กระโดดแล้วพ่นหมอกพิษ
  - **ปูเสฉวน Lv.3–4** เป็นจุดฝึกอ่านจังหวะกระดองที่แหลม · บอสแมพเดิมยังเก็บข้อมูลไว้ แต่ยังไม่เกิดในพื้นที่เริ่มต้นนี้
- **สกิลต่อสู้ 13 + สกิลเคลื่อนที่ 4** (Dash / Roll / Blink / Leap Slam) · ใหม่: ใบมีดหมุน ลูกธนูพราน สายฟ้าโซ่ ระเบิดน้ำแข็ง บึงพิษ คำสาปอ่อนแรง เสียงคำรามศึก หมาป่าวิญญาณ (อัญเชิญมาช่วยสู้)
- **Mod 15 แบบ** เปลี่ยนพฤติกรรมสกิล จำกัดด้วย Tag (เช่น ฟันซ้ำ กระแทกกระเด็น รวมพลัง ค้างนาน ดูดเลือด จ่าฝูง)
- **อุปกรณ์ 5 ช่อง** (อาวุธ เกราะ หมวก รองเท้า เครื่องราง) กว่า 30 ชิ้น อาวุธ 7 ประเภทมีโบนัสในตัวแต่ไม่ล็อกสกิล · Grade สุ่ม C/B/A/S + Option · ตีบวก +N · หมวก/เกราะเปลี่ยนหน้าตาตัวละคร
- **เครือข่าย Job 87 โหนด:** ลาก/ซูมผัง เชื่อมสายร่วม ดูเส้นทางล่วงหน้า แล้วกดลงแต้ม; เลือกอาชีพหลักหนึ่งสาย โหนดเฉพาะยังต้องมีอาชีพนั้น
- **Soft Targeting**, Basic Attack เป็นสกิลที่ถอดได้, Stat Points / Job Points / Job Tree, รีแต้มด้วยเงินในเกม
- **UI สำหรับเล่นจริง:** ปุ่มกระเป๋า/สกิลเข้าถึงตรง เมนูอื่นรวมในปุ่มเมนู · ภารกิจย่อได้ · แถบสกิล PC และปุ่มสัมผัสมีชื่อ/MP/คูลดาวน์ · กระเป๋าแยกอุปกรณ์/วัตถุดิบ/ม็อด พร้อมเทียบของก่อนสวม · จัดสกิลทีละช่อง · สูตรคราฟต์กรองเฉพาะที่ทำได้ · ปุ่มปิดเมนูอยู่กับที่ทั้งจอแนวตั้งและแนวนอน
- **กราฟิก/อนิเมชั่น:** พื้นผสมถนน/หิน/โคลนตามความสูงและความชัน เงาเมฆ ต้นไม้ไหวตามลม ตัวละครขยับแบบนุ่ม (เดิน-วิ่งผสมกัน ผม/ผ้าพันคอพลิ้ว เอนตัวตอนเลี้ยว คอมโบฟัน 3 จังหวะ) มอนมีท่าหายใจ/เดิน/ตั้งท่า/โดนตี
- ปรับกราฟิกได้ 3 ระดับ
- **คอมแบท:** ฟันต่อเนื่อง 3 จังหวะ ครั้งที่ 3 เป็นท่าปิดท้าย (แรงขึ้น + กระแทกกระเด็น) · มอนทั่วไปสะดุ้งหยุดชั่วครู่เมื่อโดนตี (แต่ท่าที่ตั้งท่าแล้วยังออกเสมอ บอสไม่สะดุ้ง) · หยุดภาพสั้น ๆ ตอนคริ/ท่าปิดท้าย · มอนเด้งถอยตอนโดน · ขอบจอแดงเมื่อโดนตีและตอน HP ต่ำ
- **แถบ EXP / Job อยู่ขอบล่างสุดของจอ** เต็มความกว้าง พร้อมเปอร์เซ็นต์

เพิ่มมอนชายฝั่ง: สไลม์เกลือ นกนางนวลชายฝั่ง และปูเสฉวน พร้อมรูป โมเดล ท่าตั้งโจมตี ของดรอป และสูตรคราฟต์ใหม่; ปูเดิมปรับให้เหมาะกับผู้เล่นใหม่

## วิธีเล่น

| | PC | iPad / มือถือ |
|---|---|---|
| เดิน | WASD | จอยซ้าย (แตะตรงไหนก็ได้ครึ่งซ้าย) |
| เล็ง | เมาส์ | ทิศที่เดิน / ลากปุ่มสกิล |

| หลบ | Space / Shift | ปุ่มหลบ (ปัดเพื่อเลือกทิศ) |
| เมนู | I กระเป๋า · K สกิล · J Job · C ตัวละคร · L ภารกิจ · M แผนที่ · Esc ตั้งค่า/เซฟ | ปุ่มมุมขวาบน |
| ใช้โต๊ะคราฟต์ / ครูฝึก / หินวาร์ป | E | ปุ่มที่ขึ้นเมื่อเข้าใกล้ |

## รันบนเครื่อง

```bash
npm install
npm run dev          # เปิด http://localhost:5173 (ใช้ --host จึงเปิดจาก iPad ในวง Wi-Fi เดียวกันได้)
npm test             # unit tests ของ core (Node, ไม่ต้องใช้เบราว์เซอร์)
npm run build        # สร้าง dist/ สำหรับ deploy
npm run test:browser # smoke test ใน Chromium (ต้อง build ก่อน)
npm run test:dreamloop # ตรวจเครือข่าย + ถ่ายภาพฉากจุดเดิม 7 จุด (ต้องเปิดภาพตรวจด้วย; ไม่รันใน CI แล้ว)
npm run test:ux      # กดคราฟต์/สวมของ/ใส่ Mod + ทดสอบยกเลิกการลาก บน PC, iPad, โทรศัพท์
node tests/browser/capture.mjs   # ถ่ายภาพฉากต่าง ๆ ไว้ตรวจงานศิลป์
```

URL options: `?fresh=1` (ข้ามหน้าแรก ตัวละครใหม่ ไม่บันทึก · ใช้กับเทสต์), `?kit=bow|staff`, `?seed=123`, `?quality=low|medium|high`

## โครงสร้าง

```
data/            ข้อมูลเกมทั้งหมด (JSON): สกิล, Mod, มอน, ไอเทม, สูตรคราฟต์, เลเวล/Job, Job Tree, แมพ
src/core/        กฎของเกมล้วน ๆ (ไม่มี Three.js/DOM) → ส่วนที่ต้องแปลงเป็น GDScript ตอนย้าย
src/render/      Three.js: พื้น/น้ำ, ต้นไม้/เมือง/ซาก, ตัวละคร, มอน, เอฟเฟกต์, กล้อง
src/ui/          HUD, จอย/ปุ่ม, เมนู
tests/core/      unit tests ของกฎเกม
tests/browser/   smoke test, perf probe, art captures (Playwright)
scripts/         export-layout.mjs (ส่งออกผังแมพและ heightmap เป็น JSON ให้ Godot)
docs/            ดีไซน์, สถานะ, คู่มือย้าย Godot, ภาพอ้างอิง
```

## Deploy

`npm run build` แล้ว host โฟลเดอร์ `dist/` ที่ไหนก็ได้ (static site) เช่น Vercel หรือ GitHub Pages
ไฟล์ build ใช้ path แบบ relative จึงวางใน sub-folder ได้
