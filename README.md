# Greenhollow Frontier — Demo 1 แมพ

เดโมเกมแนว **Anime top-down MMORPG + Buildcraft** เล่นบนเว็บได้ทั้ง PC และ iPad/มือถือ
สร้างด้วย **Three.js** โดยแยก "กฎของเกม" และ "ข้อมูลเกม" ออกจากส่วนแสดงผล เพื่อพร้อมย้ายไป **Godot** ในอนาคต

เอกสารออกแบบต้นฉบับ: [`docs/DESIGN-SUMMARY-TH.txt`](docs/DESIGN-SUMMARY-TH.txt) ·
สถานะเทียบกับดีไซน์: [`docs/DESIGN-STATUS.md`](docs/DESIGN-STATUS.md) ·
คู่มือย้ายไป Godot: [`docs/GODOT-PORT.md`](docs/GODOT-PORT.md)

## ใน Demo มีอะไร

- **แมพเดียวที่มี Journey:** นิคมชายแดน (เขตปลอดภัย) → ทุ่งหญ้า → ป่า → สะพานข้ามแม่น้ำ → ที่ชุ่มน้ำ → ซากโบราณ → บอส **Horned Warden**
- **กล้อง 3/4 แบบ ARPG** สไตล์อนิเมะ cel-shaded สัดส่วนตัวละครปกติ (ไม่ Chibi) ตามภาพอ้างอิงใน `docs/reference/`
- **Soft Targeting:** มอนเข้าระยะแล้วล็อกเป้าอัตโนมัติ หันไปหาตัวอื่นก็เปลี่ยนเป้า ออกนอกระยะก็ปล่อยเป้า ตัวละครไม่วิ่งตามเป้าเอง สกิลวงกว้างเล็งตำแหน่งบนพื้นได้โดยไม่ต้องล็อกเป้า
- **Basic Attack เป็นสกิลหนึ่ง** ถอดออกหรือเปลี่ยนได้ มี 4 ช่องสกิลต่อสู้ และมี **ช่องสกิลเคลื่อนที่แยก** (Dash / Roll / Blink) ทำงานแบบชาร์จ
- **Skill + Mod:** Mod เปลี่ยนพฤติกรรมของสกิล เช่น แตกกระสุน ทะลุ เด้ง ทิ้งไฟบนพื้น สะท้อนซ้ำ เปลี่ยนธาตุ โล่หนาม หรือร่ายเองเมื่อหลบ โดยจำกัดการใส่ด้วย Tag
- **Character Level → Stat Points** และ **Job Level → Job Points** ใช้เดิน Job Tree แบบอ่านง่าย 4 สาย เลือก Job ได้ตอน Job Lv.5 (ไม่ต้องเลือกตอนสร้างตัว)
- **รีแต้มด้วยเงินในเกม** ทำได้ในนิคม
- **มอนดรอป Material ของตัวเอง** (หนัง เขี้ยว กระดอง ต่อมพิษ แกน ผงเรืองแสง เขา) Material ทุกชิ้นมีที่ใช้ ทั้งคราฟต์ อัปสกิล อัป Mod ตีบวก และขาย
- **คราฟต์อุปกรณ์ได้ Grade สุ่ม (C/B/A/S) พร้อม Option** ที่ขึ้นกับวัตถุดิบ และ **ตีบวก (+N)** เป็นระบบแยกจาก Grade
- มอน 3 ชนิดที่อ่านพฤติกรรมได้ + บอส 1 ตัว
  - หมูป่า: ตั้งท่าก่อนพุ่ง ถ้าพุ่งชนหินจะมึน
  - ด้วง: หดกระดองเมื่อโดนรัว แล้วพ่นพิษ
  - ภูตไฟ: รักษาระยะและวาร์ปหนี
  - บอส: ฟันกวาด พุ่งเขา ทุบพื้น และเกิดคลื่นกระแทกเมื่อคลั่ง
- เซฟอัตโนมัติในเบราว์เซอร์ ปรับกราฟิกได้ 3 ระดับ

## วิธีเล่น

| | PC | iPad / มือถือ |
|---|---|---|
| เดิน | WASD | จอยซ้าย (แตะตรงไหนก็ได้ครึ่งซ้าย) |
| เล็ง | เมาส์ | ทิศที่เดิน / ลากปุ่มสกิล |
| สกิล 1–4 | คลิกซ้าย, คลิกขวา, 3, 4 (หรือ 1–4, Q, R) | แตะ = ใช้กับเป้าอัตโนมัติ · ลาก = เล็งเอง |
| หลบ | Space / Shift | ปุ่มหลบ (ปัดเพื่อเลือกทิศ) |
| เมนู | I กระเป๋า · K สกิล · J Job · C ตัวละคร · Esc ตั้งค่า | ปุ่มมุมขวาบน |
| ใช้โต๊ะคราฟต์ / ครูฝึก | E | ปุ่มที่ขึ้นเมื่อเข้าใกล้ |

## รันบนเครื่อง

```bash
npm install
npm run dev          # เปิด http://localhost:5173 (ใช้ --host จึงเปิดจาก iPad ในวง Wi-Fi เดียวกันได้)
npm test             # unit tests ของ core (Node, ไม่ต้องใช้เบราว์เซอร์)
npm run build        # สร้าง dist/ สำหรับ deploy
npm run test:browser # smoke test ใน Chromium (ต้อง build ก่อน)
node tests/browser/capture.mjs   # ถ่ายภาพฉากต่าง ๆ ไว้ตรวจงานศิลป์
```

URL options: `?fresh=1` (ไม่ใช้เซฟ), `?seed=123`, `?quality=low|medium|high`

## โครงสร้าง

```
data/            ข้อมูลเกมทั้งหมด (JSON): สกิล, Mod, มอน, ไอเทม, สูตรคราฟต์, เลเวล/Job, Job Tree, แมพ
src/core/        กฎของเกมล้วน ๆ (ไม่มี Three.js/DOM) → ส่วนที่ต้องแปลงเป็น GDScript ตอนย้าย
src/render/      Three.js: พื้น/น้ำ, ต้นไม้/เมือง/ซาก, ตัวละคร, มอน, เอฟเฟกต์, กล้อง
src/ui/          HUD, จอย/ปุ่ม, เมนู
tests/core/      unit tests ของกฎเกม
tests/browser/   smoke test, perf probe, art captures (Playwright)
scripts/         export-layout.mjs (ส่งออกผังแมพเป็น JSON ให้ Godot)
docs/            ดีไซน์, สถานะ, คู่มือย้าย Godot, ภาพอ้างอิง
```

## Deploy

`npm run build` แล้ว host โฟลเดอร์ `dist/` ที่ไหนก็ได้ (static site) เช่น Vercel หรือ GitHub Pages
ไฟล์ build ใช้ path แบบ relative จึงวางใน sub-folder ได้
