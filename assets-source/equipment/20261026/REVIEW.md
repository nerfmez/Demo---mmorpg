# Visual review

ตรวจภาพต้นแบบ 13 ชุดแบบ 4 มุมบนเบสตัวละครเดียวกัน และตรวจรหัสอ้างอิงกับไอคอนของ PR #152

- 3 ชุดที่ผู้ใช้เลือกไว้ล่าสุด (wisp, mirrorwing, fernstep) เก็บภาพ JPEG ต้นฉบับตรงไฟล์ พร้อมกางเกงตามภาพ
- ชุดอื่นใช้ภาพรอบล่าสุดที่จัดไว้ในงานนี้; hood ของ wardenstalker อยู่บนศีรษะตามแบบแก้ไข
- เครื่องแต่งกายเปิดส่วนสะโพก/ขาในชุดอื่นยึดภาพร่างล่าสุด; สถานะนี้เป็นต้นแบบภาพ ไม่ใช่การยืนยันการนำเข้าเกม
- แต่ละภาพแสดงด้านหน้า มุมเฉียง ด้านข้าง ด้านหลัง และระบุไฟล์ต้นทางพร้อม SHA-256 ใน provenance.json

เปลี่ยนเฉพาะ `assets-source/` ไม่มีการแก้ `data/items.json`, runtime หรือไฟล์โมเดลในเกม จึงไม่มีการรันทดสอบเกมสำหรับ PR งานเก็บภาพต้นแบบนี้
