## ประเด็นที่ยังไม่ปิด

1. **ช่วงเลเวลของพื้นที่ติดกันยังไม่คาบเกี่ยวครบตามโจทย์เดิม.** แพตช์นี้ทำทางผ่านและระยะถอยทางกายภาพ ไม่ได้แปลงพื้นที่ที่ต่างกันหลายเลเวลให้เป็นช่วงเดียวกัน. การทำแถบเลเวลย่อยต้องเสนอพร้อมผลต่อ zone drops/สูตร/ความยากให้เจ้าของตัดสินก่อน ไม่ใส่ตัวเลขใหม่เงียบ ๆ.
2. เส้นทางแบบ minimax ไม่ได้ดีขึ้นทุกจุด: จำนวนจุดที่ต้องสัมผัส envelope เกินช่วงของตัวเอง Azure15→15 และ Frontier17→19 (ส่วนใหญ่เป็นมอนต่างช่วงในพื้นที่เดียวกัน). เป้าหมายนี้ไม่เท่ากับเกณฑ์ถนน/รอยต่อ จึงไม่ลบผลหรือเรียกว่า regression ผ่านทั้งหมด. กลุ่ม stalker ใน ruins21–23 ยังมี envelopeมอน24ในทางเข้า. ต้องตรวจความหนาแน่นทั้งฝูงและการเดินเล่นจริงก่อนรับ gameplay ครบ.
3. ยังไม่ได้ทดสอบการฟาร์มจากเริ่มเกมต่อเนื่องหรือปาร์ตี้/healer/tank. ไม่มีการรีบาลานซ์อาชีพจากสคริปต์ควบคุมสามแบบ.
4. Full-game browser navigation ในสภาพแวดล้อมนี้ถูกบล็อกด้วย `ERR_BLOCKED_BY_ADMINISTRATOR`; ไม่อ้างว่าภาพใหม่คือ integrated browser pass. ภาพเก่า40ภาพและUI results95f2a191ไม่ครอบคลุม candidateรอบนี้. ยังไม่มี iPadเครื่องจริงหรือภาพ3มิติใหม่ยืนยันถิ่นเสฉวน.
5. เครื่องมือ GitHub รอบนี้อ่านได้แต่ไม่มี actionเขียน; **ไม่มี commit ใหม่/remote PR update.**

## Godot-port addendum

`encounters.json` เพิ่ม wanderMargin, transitions(from/to/clearance), quietRoads, quietRoadMaxLevel และ shoreKindsในhabitat. ใช้ระยะจุดถึงrectangle/segmentและcoast signed distanceในGodotก่อนรับตำแหน่ง. ไม่เพิ่มกฎ AI, collision wall, safe statusหรือข้อมูลเซฟ. Atlasและsimulationต้องแชร์ layout เดียวกันเช่นเดิม.
