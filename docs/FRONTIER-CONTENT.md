# สกิลและม็อดชุดทดลอง

สร้างกลไกก่อนตามคำขอผู้ใช้ สูตรคราฟต์จะออกแบบภายหลัง รายการนี้เป็นค่าตั้งต้นทดลอง
ไม่ใช่บาลานซ์สุดท้าย ข้อมูลตัวเลขที่ใช้จริงอยู่ใน `data/skills.json` และ `data/mods.json`

รวม 27 สกิลต่อสู้ / 4 สกิลเคลื่อนที่ / 34 ม็อด โดยเพิ่ม 14 สกิลและ 19 ม็อด

## สกิลใหม่

| สกิล | หน้าที่และเงื่อนไข |
|---|---|
| ชาร์จยิงรุนแรง (`charged_shot`) | กดค้างเพื่อชาร์จจนเต็มใน 1.2 วินาที ปล่อยเพื่อยิง ความแรง 100–250% ระหว่างชาร์จเดินได้ 40% ใช้ 8 MP และลูกธนูเมื่อปล่อยยิง ยกเลิกได้โดยไม่เสียทรัพยากร |
| ตั้งรับสวนกลับ (`riposte`) | ตั้งรับด้านหน้า 0.8 วิ รับสำเร็จลดดาเมจและเปิดจังหวะกดซ้ำสวนกลับใน 1.5 วิ ต้องถือดาบ |
| แทงจุดอ่อน (`weakpoint`) | แทงเป้าในวงแคบจากด้านข้างหรือด้านหลังแรงขึ้น 60% ไม่วาร์ปเข้าหาเป้า |
| ฟันเปิดเกราะ (`armor_cleave`) | ฟันวงแคบและเปิดเกราะ 18% นาน 5 วิ ใช้ค่าที่แรงที่สุด ไม่ซ้อนลดเกราะ |
| ทุบขัดจังหวะ (`interrupt_slam`) | ทุบขัดท่าที่ขัดได้ของมอนทั่วไป บอสสะสมค่าการเสียหลักเฉพาะท่าที่กำหนด |
| ผ่าแนวหน้า (`frontline_split`) | เตรียมฟันหนัก 0.65 วิ แล้วฟันแนวตรงกว้าง 1.4 ม. หันทิศระหว่างเตรียมได้และเดินช้า |
| กระแทกโล่ (`shield_bash`) | กระแทกวงแคบด้านหน้า ผลักและเรียกความสนใจ ต้องมีโล่ที่ใช้งานได้ |
| ฝนลูกธนู (`arrow_rain`) | วางวง 3 ม. ลูกธนูตก 3 ระลอก เว้น 0.4 วิ ใช้ลูกธนู 3 ลูกพื้นฐาน เป้าหมายเดินออกได้ |
| กระสุนเวทพื้นฐาน (`arcane_shot`) | ยิงกระสุนเวทเบาโดยไม่ใช้ MP ไม่มีสถานะติดตัว ต้องถือไม้กายสิทธิ์ ถอดออกจากช่องได้ |
| ธารเพลิง (`flame_stream`) | กดค้างร่ายไฟกรวย 5 ม. หลังเตรียม 0.2 วิ เดินได้ 40% ใช้ MP ต่อเนื่อง ปล่อยเพื่อหยุด |
| กำแพงผลึก (`crystal_wall`) | วางแนวผลึกชั่วคราวยาว 4 ม. แบ่งเป็นท่อนที่มอนทำลายได้ ต้องมีทางอ้อมและไม่ทับตัวละคร |
| ชำระบาดแผล (`cleanse`) | ฮีลเป้าพันธมิตรที่บาดเจ็บในระยะ หรือฮีลตนเอง ล้างพิษหรือความเย็นหนึ่งอย่าง ไม่ล้างกลไกบอส |
| วงจังหวะรบ (`battle_aura`) | เปิด/ปิดวงฟื้น MP รอบตัว 5 ม. สำรอง MP สูงสุด 20% พันธมิตรต้องอยู่ในระยะ |
| ผู้พิทักษ์ศิลา (`stone_guardian`) | อัญเชิญผู้พิทักษ์รับการโจมตี 25 วิ เดินช้า โจมตีเบา ล่อมอนใกล้ ๆ ให้โจมตีตนเอง |

## ม็อดใหม่

| ม็อด | ผลและข้อแลกเปลี่ยน |
|---|---|
| ก้าวสั้นถี่ (`short_stride`) | ระยะเคลื่อนที่ลดลง 50% แลกกับชาร์จสูงสุด +1 คืนชาร์จต่อครั้งเท่าเดิม ไม่เพิ่มดาเมจหรือเวลาอมตะ ใส่ในช่องม็อดเคลื่อนที่แยก |
| กระสุนย้อนกลับ (`returning_shot`) | กระสุนกลับตามเส้นเดิม ขากลับแรง 40/45/50% โดนเป้าเดิมได้หนึ่งครั้งต่อขา ใช้ร่วมกับเด้งไม่ได้ |
| ระเบิดปลายทาง (`terminal_burst`) | ระเบิดรัศมี 1.6 ม. เมื่อกระสุนสิ้นสุด แรง 35/40/45% ลดดาเมจกระทบตรง 20% |
| สายฟ้าหวนคืน (`chain_return`) | สายฟ้าเด้งครบแล้วกลับเป้าแรกอีกครั้ง แรง 40/45/50% ลดดาเมจทั้งหมด 15% |
| ก้าวตามคม (`advancing_edge`) | ก้าวตามทิศเล็ง 0.8/1/1.2 ม. ก่อนฟัน ลดมุมฟัน 25% ไม่มีอมตะ |
| กวาดรวมศัตรู (`gathering_cut`) | ดึงมอนทั่วไป 1/1.3/1.6 ม. เข้าศูนย์กลาง ลดดาเมจ 20% บอสไม่ถูกย้าย |
| แผลฉีก (`laceration`) | เปลี่ยนดาเมจตรง 25% เป็นเลือดไหล 3/3.5/4 วิ รวมดาเมจเท่าเดิม ดาเมจต่อเนื่องไม่มีคริหรือทริกเกอร์ |
| เถ้าระเบิด (`ash_detonation`) | กินเผาไหม้ที่ตนสร้างเพื่อระเบิดวง 1.8 ม. แรงตามดาเมจเผาที่เหลือสูงสุด 60/70/80% ของฮิต ลดฮิต 15% |
| ผลึกแตก (`shatter`) | โดนเป้าที่เย็นอย่างน้อย 30% แล้วแตกผลึกวง 1.5 ม. แรง 25/30/35% ลดความเย็นเป้าและลดฮิต 10% |
| พื้นที่เคลื่อนตาม (`following_field`) | วงตามผู้ร่าย รัศมีลดลง 35% มีวงเดียวต่อช่องสกิล |
| พื้นที่เหนี่ยวรั้ง (`binding_field`) | อยู่ในวงนานค่อยช้าลง สูงสุด 35/40/45% ลดดาเมจ 20% ออกจากวงผลหมดใน 0.6 วิ |
| ฮีลส่งต่อ (`healing_chain`) | ฮีลเด้งไปพันธมิตรที่บาดเจ็บใกล้ ๆ อีก 1/2/2 ตัว ผลลดลง 30% ต่อครั้ง ไม่เด้งวน |
| ฮีลเป็นเกราะ (`healing_barrier`) | แบ่งฮีล 25/30/35% เป็นเกราะ 4 วิ เกราะสูงสุด 30% HP ไม่สะสมจากฮีลซ้ำ |
| เกราะแตกผลัก (`breaking_ward`) | เกราะที่ถูกทำลายผลักมอนรอบตัว 1.5/1.8/2.1 ม. ในรัศมี 3 ม. เกราะเริ่มต้นลด 20% |
| คำสาปแพร่ต่อ (`spreading_hex`) | เป้าที่ตายส่งคำสาปเวลาที่เหลือให้เป้าใกล้หนึ่งตัว ระยะ 3/4/5 ม. ไม่เริ่มเวลาใหม่ |
| คำสั่งผูกเป้า (`focused_pack`) | อัญเชิญเน้นเป้าที่ผู้เล่นโจมตีล่าสุด แรงขึ้น 15/20/25% ต่อเป้านั้น ต้องรอ 0.6 วิเมื่อเปลี่ยนเป้า |
| พันธะคุ้มกัน (`guardian_bond`) | อัญเชิญในระยะ 4 ม. แบ่งรับฮิตเจ้าของ 15/20/25% แลกกับดาเมจอัญเชิญลด 25% มีเพดานรวม ไม่แบ่งซ้ำหลายตัว |
| บัฟเป็นวงติดตาม (`following_aura`) | เปลี่ยนบัฟเป็น Aura สำรอง MP 25% ให้ผล 50/55/60% ของเดิม พันธมิตรต้องอยู่ในระยะ |
| ร่ายเมื่อรับสำเร็จ (`cast_on_guard`) | เมื่อรับด้วยโล่หรือท่ารับสำเร็จ ร่ายสกิลนี้โดยใช้ MP คูลดาวน์ภายใน 3/2.7/2.4 วิ ผล 60/65/70% ไม่มีทริกเกอร์ต่อ |

## วิธีลอง

- หน้าเกม: `?fresh=1&skillSandbox=1&quality=low` ตัวละครทดลองไม่บันทึกเซฟ
- หน้า Skill Lab: `lab.html?skill=charged_shot` เลือกสกิลและม็อดในหน้าทดลอง
- ชาร์จยิง: กดค้าง แล้วปล่อยยิง; ลากเพื่อเล็ง ยกเลิกเมื่อเปิดเมนู/ใช้การเคลื่อนที่
- ม็อดเคลื่อนที่: สมุดสกิล → เคลื่อนที่ → เลือกก้าวสั้น ช่องแยกใส่ได้หนึ่งเหรียญ
- อัญเชิญ: ใช้ปุ่มโจมตีเป้า/กลับมา/คุ้มกันที่ปรากฏเมื่อมีอัญเชิญ

ข้อจำกัด: ยังไม่มีสูตรหรือแหล่งปลดล็อกปกติสำหรับเนื้อหาใหม่, ภาพและท่าบางส่วนเป็น
ต้นแบบ, ผู้พิทักษ์ศิลาใช้โมเดล crag_golem ชั่วคราว, Battle Aura ฟื้น MP ให้เจ้าของ
เพราะอัญเชิญปัจจุบันไม่มี MP. สกิลพื้นฐานคทาไม่มีค่ามานาแต่มีคูลดาวน์ตามข้อมูล

ม็อดตรวจแท็กพื้นฐานและรูปแบบร่าย ไม่ให้เด้ง/ย้อนกลับใช้ร่วมกัน, ดึง/ผลักขัดกัน,
Aura และทริกเกอร์เคลื่อนที่ขัดกัน การแตกผลึกต้องมีธาตุน้ำแข็งที่ใช้งานได้จริง
ตัวกระตุ้นไม่กระตุ้นซ้ำเป็นลูกโซ่ ดาเมจ/เกราะ/ฮีล/วงคงอยู่มีขอบเขตตามกติกาทดสอบ
