# ถ้ำมุกในเปลือกหอยยักษ์ (Pearlshell Grotto)

ดันเจี้ยนจากภาพคอนเซปของเจ้าของ (`docs/reference/shell-grotto-concept.jpg`) เป็น**หน้าแยก** (`dungeon.html`)
ที่เข้าจาก **หอยสังข์ยักษ์ขับขาน (Singing Conch)** บนหาดหอยสังข์ในเกมจริง (เจ้าของ 30 ต.ค. 2026)

## เปิดดู

- ในเครื่อง: `npm run dev` แล้วเปิด `/dungeon.html` · หลัง build: `dist/dungeon.html`
- ในเกม: เดินไปข้างหอยสังข์ยักษ์ ปุ่ม **เข้าไปในหอยสังข์** จะขึ้น (หรือกด E)
- เปิดหน้าตรง ๆ ได้เป็นหน้าตัวอย่าง (ฮีโร่ชุดเริ่มต้น ประตูมุกพากลับไปหน้าแรกของเกม)
- ตัวเลือก URL: `?view=overview` เริ่มที่ภาพรวม, `?post=0` ปิดการเกรดสีจอ
- เดิน: ลากนิ้วทางซ้ายของจอ (จอยลอย) หรือ WASD / ลูกศร · ปุ่มม่วงขวาล่างขึ้นเมื่อมีสิ่งให้ทำ · **ภาพรวม** ดูทั้งแผนที่ · ＋/－ ซูม

## ทางเข้าและทางออก

- ทางเข้าคือหอยสังข์ในเกม: landmark `giant_conch` ใน `data/maps/frontier-wilds.json` มี `dungeon: {id: "shell-grotto", r: 7.5}`
  - ในรัศมี `r` `OpenWorldGame.nearby().dungeon` บอกชื่อดันเจี้ยน และ HUD ขึ้นปุ่ม
  - `enterDungeon(id)` เช็กว่าอยู่ใกล้ ไม่ตาย ไม่อยู่ในการต่อสู้ แล้วส่ง event `enterDungeon`
  - `main.js` เซฟสล็อต แล้วจด trip ไว้ใน sessionStorage `frontier.dungeon` (`stashDungeon`: สล็อตหรือตัวละครทดลอง หน้าตาและชุดของฮีโร่) แล้วเปิด `dungeon.html`
- ในถ้ำ ฮีโร่เริ่มที่ `spawn` ด้วยหน้าตาและอาวุธเดียวกับในเกม
- ทางออกคือประตูหินแสงมุก (`shell-exit`, `to: "game"`) ในห้องแรก
  - เดินเข้าไปหรือกดปุ่ม **ออกจากเปลือกหอย** แล้ว `leaveDungeon()` จะส่ง trip กลับเป็นการเดินทางของเกม (`frontier.travel`)
  - เกมโหลดตัวละครที่ตำแหน่งที่เซฟไว้ คือข้างหอยสังข์
- ฉากเปลือกหอยบนหาดของหน้าตัวอย่าง (`outside`) เลิกใช้แล้ว เจ้าของบอกว่าไม่ต้องมี

## ผัง: ลอกจากภาพคอนเซปโดยตรง

ผังในถ้ำ**ไม่ได้กะเอง**แต่ลอกจากภาพ (`scripts/grotto-trace.py`)
- สคริปต์หาพื้นหิน (สีครีมอุ่น) กับน้ำ (สีฟ้าเขียว) ในภาพ แล้วล้างจุดรบกวน (เงาเสา ของประดับ)
- แบ่งภาพเป็นโซนตามความสูง แล้วเขียนขอบพื้นเป็นรูปหลายเหลี่ยม (มีรูสำหรับเกาะหิน) ลง `shell-grotto.json` ส่วน `inside`
- ค่าทุกอย่างของการลอกอยู่ใน `data/dungeons/shell-grotto-trace.json` เป็นพิกัดพิกเซลของภาพ ได้แก่ โซนและความสูง บันได ของประดับ (`face` คือจุดที่หันไปหา) น้ำตก ไฟ ชื่อพื้นที่ และพื้นที่ที่ภาพบังไว้ (`fill`)
- อัตราส่วน: 0.11 ม./พิกเซล ตามแนวนอน และ 0.1375 ม./พิกเซล ตามแนวลึก (ภาพมองเฉียงลงมา) ขยายจาก 0.08/0.1 เพราะเจ้าของบอกว่าพื้นที่แคบเกินไป ถ้ำทางเข้าจึงกว้างราว 34 × 34 ม.
- โซนที่มีผนังสูง (`round` เป็นพิกเซล) จะเกลาขอบให้มน เพราะหินและของประดับที่วาดทับขอบพื้นในภาพจะทำให้ผนังเป็นร่องและนิ้วยื่น
- แก้ผังที่ไฟล์ trace แล้วรัน `python3 scripts/grotto-trace.py` (ต้องมี numpy และ opencv-python) ห้ามแก้ส่วน `inside` ตรง ๆ

| โซน | ความสูง (ม.) | ในภาพ |
|---|---|---|
| `west` ทางลาดปะการัง ทางเดินหลัก ซุ้มประตูผนึก | 0 | ทางคดซ้ายกลาง และทางเดินบนจากกลางไปขวา |
| `entrance` ถ้ำประตูมุก | 0 (โทนอุ่น) | ซ้ายล่าง |
| `hoard` ห้องสมบัติลับ | 1.2 | ซ้ายบน ลงบันไดมาที่ทางเดินหลัก |
| `pool` เกาะหัวใจปะการัง | หิน −0.5 / พื้นน้ำ −0.9 | กลาง มีบันไดลงจากทางเดิน |
| `temple` วิหารจมน้ำ | หิน −4.0 / พื้นน้ำ −4.4 | ขวาล่าง บันไดลงจากเกาะ |
| `throne` / `dais` บัลลังก์ | น้ำ 1.6 / หิน 2.0 / แท่น 2.8 | ขวาบน บันไดขึ้นจากทางเดิน |

## ทำทีละโซน: ถ้ำประตูมุกเสร็จก่อน

เจ้าของให้ทำทีละโซนจนได้คุณภาพแล้วค่อยไปโซนถัดไป และให้ใช้ Blender ทำ asset โซนที่ทำแล้วมี `style: "cave"` ในไฟล์ trace
(ตอนนี้มีแค่ `entrance`) โซนอื่นยังเป็นแบบเดิม

- **ผนังถ้ำสูง** (เจ้าของ: "ผนังให้ดูเป็นถ้ำสูงมากขึ้น"): ผนังด้านหลัง (ด้านที่หันออกจากกล้อง) สูงราว 7–10 ม. เป็นหินย้อยเป็นริ้วแนวตั้ง
  มีชายคาหินยื่นออกมาด้านบนพร้อมหินงอกห้อยลงมา ด้านบนผนังมีหินก้อนใหญ่เกาะเป็นเปลือก ส่วนด้านที่หันเข้ากล้องต่ำราว 1.5 ม.
  เป็นกองหินก้อนใหญ่ กล้องจึงยังเห็นพื้นในถ้ำ ด้านข้างค่อย ๆ ไล่ความสูง ด้านหลังประตูมุกมีช่องเว้าเข้าไปในผนัง ปลายผนังที่ทางออกไปทางลาดปะการังค่อย ๆ ลดลงแล้วจบด้วยก้อนหิน
- **พื้นเก่า** (เจ้าของ: "พื้นยังดูถูกปูมาดีไม่เก่าแก่"): ไม่ใช่แผ่นหินเรียงตารางแล้ว แต่เป็นหินรูปทรงไม่เท่ากัน ทั้งแผ่นใหญ่ กลาง และเล็ก
  มุมสึกและบิ่น บางแผ่นแตกเป็นสองซีก บางแผ่นเอียงหรือจมลงไปในดิน หลายแผ่นหายไปเป็นหย่อม ๆ เหลือดินกับเศษหิน
  แผ่นที่อยู่ใกล้ผนังสกปรกกว่าและหายมากกว่า บางแผ่นมีคราบมอส
- **แสง**: ในถ้ำมืด มีแสงอุ่นจากประตูมุกกับไฟในห้อง และมีไฟดวงเล็กเดินตามตัวละคร
- โมเดลจาก Blender มีสองไฟล์ ทั้งสองสร้างด้วย Blender 4.2 แบบไม่เปิดหน้าจอ (`blender -b --python <script>`)
  - `scripts/blender/grotto-kit.py` → `public/models/grotto/grotto-kit.glb` ชิ้นส่วนใช้ซ้ำ: ซุ้มประตู หีบ ลัง เสาหิน ปะการังพุ่มกับปะการังพัด และหิน
  - `scripts/blender/grotto-cave.py` → `public/models/grotto/grotto-cave.glb` ตัวถ้ำของทุกโซน `cave` สร้างจากขอบพื้นจริงในแผนที่
    (`scripts/grotto-cave-input.mjs` ใช้กฎเดินของเกมบอกว่าขอบตรงไหนเป็นผนัง ตรงไหนเป็นทางไปห้องอื่น)
    แต่ละพื้นมีสามชิ้น: `cavefloor_<id>` พื้นหิน, `cavewall_<id>` ผนังหิน และ `caverock_<id>` ก้อนหิน หินงอก และเศษหิน
    เงาตามซอก (ambient occlusion) อบไว้ในสีจุดยอดด้วย Cycles ส่วนแสงจริงมาจากไฟในเกม
- **หอยมือเสือเก็บไข่มุก** (ของประดับ `giantClam` ชิดผนังหลังถ้ำประตูมุก) รูปทรงสร้างด้วย Meshy จากรูปอ้างอิงรูปเดียว
  `docs/reference/giant-clam-pearl.png` (image-to-3D แบบ smart topology ไม่มี texture เก็บไว้ที่ `assets/meshy/grotto/giant_clam_meshy.glb`)
  แล้วลงสีเองใน Blender: `scripts/blender/grotto-clam.py` → `public/models/grotto/giant-clam.glb` (ฝาบน `clam_lid`, ฝาล่างกับเนื้อหอย `clam_cup`, ไข่มุก `clam_pearl`)
  สคริปต์เพิ่มความหนาให้ฝา แบ่งหน้าเรียบขึ้นหนึ่งระดับ แล้วระบายสีลงจุดยอด: ยอดลอนสีครีม ร่องลอนกับครึ่งล่างสีฟ้าอมเขียวขอบหยักแบบแปรงแห้ง
  ขอบด้านในสีมุกม่วง เนื้อหอยสีพีชมีรอยพับเข้ม เพรียงสีเทา ปะการังสีส้มแดง ไข่มุกสีรุ้ง แล้วอบเงาตามซอกด้วย Cycles
  `src/render/grotto/clam.js` โหลดไฟล์ ใส่วัสดุ cel กับเส้นขอบ และให้ไข่มุกเรืองแสงเบา ๆ
  (ก่อนหน้านี้ลองเขียนเป็นสมการตามขั้นตอน img2threejs ดูได้ใน commit e319ca1)
- **ปะการังเรืองแสง 6 แบบ** (ของประดับ `coral` และปะการังตามตีนผนังทุกห้อง) รูปทรงสร้างด้วย Meshy ครั้งเดียวทั้งแผ่น
  จากชีทของเจ้าของ `docs/reference/glow-corals.png` แบบไม่แก้รูป (smart topology ไม่มี texture เก็บไว้ที่ `assets/meshy/grotto/glow_corals_meshy.glb`)
  แล้วลงสีเองใน Blender: `scripts/blender/grotto-corals.py` → `public/models/grotto/glow-corals.glb`
  แต่ละแบบมีสองชิ้น `coral_<ชื่อ>_body` (ตัวปะการัง ลงสีจุดยอดและอบเงา) กับ `coral_<ชื่อ>_glow` (ส่วนที่เรือง: ปุ่มปลายกิ่งกับจุดเรืองตามตัว)
  ชื่อ: `purple` ต้นม่วง, `blue` ต้นฟ้า, `teal` ต้นเขียวน้ำทะเล, `tubes` ปะการังท่อ, `bubbles` ปะการังลูกโป่ง, `pink` ปะการังชมพู
  สคริปต์แยกชิ้นตามตำแหน่งในแผ่น ย้ายปุ่มที่ Meshy ทำลอยกลับไปติดกิ่ง หาปุ่มปลายกิ่งจากระยะตามผิวจากโคน
  ต้นไม้สีเข้มที่โคนอ่อนขึ้นตอนบน ปุ่มปลายมีแกนขาว ท่อมีขอบปากสีม่วงอ่อนกับด้านในเข้ม ลูกโป่งมีเซลล์กลมและจุดฟ้ากลางเซลล์
  `src/render/grotto/corals.js` ให้ตัวปะการังแบบ cel ที่เรืองสีตัวเองครึ่งหนึ่ง (เหมือนในชีทที่ทั้งตัวเรือง) ส่วนที่เรืองวาดแบบไม่รับแสง แล้ว bloom ของหน้าทำให้ฟุ้ง
  สีของ `coral` ในแผนที่เลือกแบบ: ม่วง → ต้นม่วงหรือลูกโป่ง, ฟ้า → ต้นฟ้าหรือต้นเขียว, ชมพู → ชมพู, น้ำเงิน → ท่อหรือต้นฟ้า
  ปะการังขึ้นเป็นกอแบบแนวปะการังจริง: ต้นใหญ่หนึ่งต้นตามสีที่แผนที่ขอ แล้วมีต้นเล็กคละชนิด 2-4 ต้นรอบโคน (ส่วนใหญ่เป็นชนิดเตี้ย:
  ลูกโป่ง ท่อ ต้นเขียว ชมพู ไม่ใช่ต้นเดิมย่อส่วน) ขนาด 0.3-0.65 เท่าของต้นใหญ่ ตามตีนผนังเรียงไปตามแนวผนัง บางกอสูงเป็นพิเศษ และกอไม่ซ้อนกัน
  แสงของกอตกเป็นวงนุ่ม ๆ บนพื้น ไม่ใช่วงแสงหันหาจอ (วงแบบนั้นโดนพื้นกับผนังบังจนเห็นเป็นก้อน) คริสตัลก็ใช้แสงบนพื้นแบบเดียวกัน
- **ของประดับจากชีทของเจ้าของ 5 ชีท** (`docs/reference/grotto-crystals.png`, `grotto-coral-tree.png`, `grotto-hoard.png`, `grotto-ruins.png`, `grotto-pearl-altar.png`)
  รูปทรงสร้างด้วย Meshy ชีทละครั้งแบบไม่แก้รูป (smart topology ไม่มี texture เก็บไว้ที่ `assets/meshy/grotto/*_meshy.glb`) แล้วลงสีเองใน Blender:
  `scripts/blender/grotto-props.py` (ใช้ตัวช่วยร่วม `scripts/blender/grotto_paint.py`) → `public/models/grotto/grotto-props.glb`
  Meshy แยกชิ้นมาให้แล้ว (บล็อกของเสา แถบเหล็กกับมุมทองของหีบ หินแต่ละก้อน) สคริปต์จึงลงสีแต่ละชิ้นตามว่าเป็นอะไร แล้วอบเงาตามซอก
  - คริสตัล 3 ขนาด (`crystal_s/m/l`): ผลึกฟ้าและม่วง ไล่สีจากโคนเข้มไปปลายอ่อนและเรืองสีตัวเอง หินรอบโคนมีมอส
  - ต้นปะการังใหญ่ (`coral_tree`) สูงราว 5.6 ม. ม่วงอมฟ้าที่โคนไล่เป็นชมพูที่ยอด ปลายกิ่งเรืองแสง อยู่บนเกาะหัวใจปะการัง
  - ห้องสมบัติ: หีบปิดกับหีบเปิดที่มีทอง อัญมณีและมุก (สลับกัน) เทียนบนหินพร้อมเปลวไฟเรือง ถัง ลัง เสาไม้พันเชือก
  - ซากวิหาร: เสา เสาหัก เสาล้ม ซุ้มประตูสองแบบ (สลับกัน) และซุ้มประตูผนึกที่มีวงตราเรืองแสงสีฟ้าบนบาน
    หินสีครีม บล็อกล่างอมเขียวน้ำทะเล มอสบนหลังบล็อก สาหร่ายเป็นเส้นห้อยจริงตามด้านข้าง เพรียงกับเศษหินที่โคน
  - แท่นไข่มุกยักษ์ (`pearl_altar`): ฐานทอง แถบสีเขียวน้ำทะเลมีลายนูนสีทอง มุกเม็ดเล็กรอบฐาน ไข่มุกสีรุ้ง
    (ไข่มุกของ Meshy มีรู สคริปต์ใส่ทรงกลมใหม่ขนาดเท่าเดิมแทน)
  - ชีทคริสตัลชิ้นที่สี่ (หอยมีมุก) Meshy ทำออกมาเป็นเศษ จึงไม่ได้ใช้ ไข่มุกเม็ดเล็กยังเป็นแบบเดิมของเกม
  `src/render/grotto/painted.js` โหลดไฟล์ วาดแต่ละชิ้นตามชนิดในชื่อ (`flat` เหลี่ยม, `smooth` เรียบ, `shine`/`shinesm` เรืองสีตัวเอง, `glow` ไม่รับแสง)
  เป็น instanced mesh พร้อมเส้นขอบสีเข้มโทนเดียวกัน ของประดับเหล่านี้แทนของแบบง่ายเดิมทุกห้อง (แสงก้อนกลมของคริสตัลกับต้นปะการังเปลี่ยนเป็นแสงบนพื้น)
- **การจัดวาง** ลอกจากภาพคอนเซปทีละชิ้น โดยปัก `at` ที่**ฐาน**ของของ (ในภาพมุมเฉียง ของสูงอยู่เหนือฐานของมัน ถ้าปักกลางตัวของจะถอยไปข้างหลังหลายเมตร)
  เสาสูงอยู่ข้างทางเดินและสองข้างแท่นมุก ตอเสาเตี้ยเรียงตามขอบทางและยืนในน้ำรอบวิหาร ซุ้มประตูสองซุ้มอยู่หลังแท่นไข่มุกในวิหาร
  วงกลมบนพื้นวิหารเป็น**ลายแกะสลักบนพื้นหินใต้น้ำ** (`runeCircle`, `medallionTexture`) ไม่ใช่วงเวท จึงไม่เรืองแสงและไม่หมุน
- **น้ำ** ใสแบบน้ำตื้น มองเห็นพื้นหินข้างใต้ มีตาข่ายแสงใต้น้ำเส้นบาง ๆ ที่ลอยไปช้า ๆ และประกายเล็ก ๆ ที่วับขึ้นทีละจุด (`water.js`)
- **พื้นหิน** นอกถ้ำเป็นหินตัดสี่เหลี่ยมยาวไม่เท่ากันวางเหลื่อมเป็นแถว ขอบลบมุม บางก้อนมุกบิ่นหรือร้าว (`flagstoneTexture`)
- **ปะการังเรืองแสง** หันหน้าหากล้องเสมอ เพราะทรงแบนกว้างแบบในชีท ถ้าหันตามผนังกล้องจะเห็นแค่สันบาง ๆ
- **ทรงพื้น**: ทุกโซนมี `round` เกลาขอบให้มน (ของประดับกับหินที่วาดทับขอบในภาพทำให้ขอบเป็นฟันเลื่อยและมีนิ้วยื่น)
  ทางเดินและแท่นในน้ำก็เกลาแบบเดียวกัน ส่วนพื้นหินในวิหารที่ซากวิหารในภาพบังจนลอกไม่ได้ วาดเองใน `stone` ของโซน
  (วงรีและหลายเหลี่ยม: แท่นไข่มุก ทางเดินทิศตะวันออกกับแขนลงใต้ ทางเดินเสาล้ม ลานใต้บันได และแท่นเสาสูง)
  ของประดับที่ตกขอบจะย้ายเข้ามาบนพื้นที่เขียนจริง (ไม่ใช่หน้ากากก่อนเกลา)
  ห้องบัลลังก์ก็วาดพื้นหินเองเหมือนกัน: ทางเดินตามตีนห้องถึงบันไดแท่น ลานทิศตะวันออกที่มีไข่มุก และฐานเสาสี่ต้น
- **ขอบหินทางเดิน** (`addCurbs` ใน `floors.js`) เป็นก้อนหินยกเรียงกัน ยาว 0.8-1.4 ม. เว้นร่อง 0.07 ม. สูงไม่เท่ากัน
  ขึ้นทุกขอบที่พื้นลดระดับ รวมทางเดินที่อยู่เหนือน้ำตื้นด้วย (ฮีโร่ยังลุยน้ำลงไปได้)
- **บันไดกับรอยต่อ** (`grotto-trace.py` ส่วน joints ทำบนกริด 5 ซม. ในหน่วยเมตร): บันไดยาวตามแนวที่คอนเซปวาด (ขั้นลึกแบบในภาพ ขั้นสูงราว 0.15 ม.)
  แต่หยุดที่ขอบของพื้นที่มันขึ้นหรือลงไปหา (ปลายถูกดึงกลับจนถึงขอบ ตราบที่ความชันยังเดินได้ ≤ 0.28) ไม่ขุดเข้าไปในพื้น
  พื้นที่ระดับเดียวกับปลายแต่ละข้างได้ลานสี่เหลี่ยมกว้างเท่าบันได ลึก 1.5 ม. รอยต่อจึงเป็นเส้นตรงเส้นเดียวตั้งฉากกับบันได
  - ลานซ้อนเข้าไปในบันได 0.3 ม. ระหว่างลานกับบันไดจึงไม่มีร่อง
  - ถ้าเดินต่อออกจากลานแล้วเจอช่องว่างก่อนถึงพื้นหินระดับเดียวกัน ลานจะยืดข้ามช่องนั้น (ไม่เกิน 8 ม.)
  - ลานตัดน้ำที่อยู่ใต้มันออก จึงไม่เหลือแถบน้ำที่ต่ำกว่าเป็นขั้นที่หัวหรือตีนบันได
  - เสาที่ปลูกตามขอบห้องไม่ลงในแนวบันได (ยืดออกไป 3 ม. และกว้างกว่าบันได 1 ม. ทั้งสองข้าง)
  พื้นทุกชิ้นถูกตัดให้ชิดข้างบันไดพอดี ไม่ทับและไม่เหลือร่อง (เศษพื้นที่ถูกตัดขาดเล็กกว่า 10 ตร.ม. ถูกทิ้ง)
  หินขอบไม่วางตามขอบพื้นที่ติดบันได เพราะผนังข้างบันไดทำหน้าที่นั้นแล้ว บันไดได้สีพื้นของห้องที่มันขึ้นไป
  หน้าขั้นปูแบบขั้นบันไดจริง ไม่ใช่ลายพื้นที่ถูกหั่น: ลายหินหมุนตามแนวบันได ขั้นละหนึ่งแถวของหินยาววางขวางขั้น (แถวและระยะต่างกันทุกขั้น รอยต่อจึงสลับกัน)
  และมืดลงไปทางโคนขั้นถัดไป จมูกขั้นเป็นหินตัดสีอ่อน ผนังหินสองข้างสูง 0.45 ม. (ส่วนกฎการเดินยังเดินตามทางลาด)
  วิหารจมน้ำต่ำลง 2 ม. (หิน −4.0) บันไดใหญ่จากเกาะลงวิหารจึงลงจริง 3.5 ม. แบบในคอนเซป ไม่ใช่ทางลาดแบน
- **ห้องบอสใหญ่ขึ้น** (`grow` ใน trace): ภาพและทุกจุดของห้องบัลลังก์กับแท่นถูกยืดออกจากหัวบันไดบัลลังก์ ไปทางตะวันออก 1.35 เท่า และทางเหนือ 1.5 เท่า
  การยืดค่อย ๆ หายไปทางตะวันตกและทางใต้ของห้อง ห้องอื่นจึงไม่เปลี่ยน ภาพถูกเติมขอบให้ห้องที่ยืดใส่ได้ โดยเลื่อนจุดกำเนิดตาม พิกัดเมตรของห้องอื่นจึงไม่เปลี่ยน
- **รอยต่อพื้น**: ผนังหน้าผาใต้ขอบพื้นไม่วาดตรงที่พื้นอีกชิ้นระดับเดียวกันต่ออยู่ (`addWalls` ใช้ `map.surfaceAt` ดูว่าข้างนอกเป็นอะไร)
  ถ้าข้างนอกต่ำกว่าก็วาดผนังลงไปแค่ถึงพื้นนั้น ไม่ใช่หน้าผาลงความมืด
- **ปะการังกับคริสตัล** ถูกย้ายไปชิดตีนผนัง (แถบพื้น 5-13 พิกเซลจากขอบที่ติดความมืด) ในตอนลอกผัง ส่วนต้นเล็กรอบกอต้องอยู่ห่างขอบไม่เกิน 1.6 ม. และไม่อยู่บนบันได
- **น้ำตก** ลอกตำแหน่งจากคอนเซปแล้ววางลงบนขอบจริง: แบบ `ledge` ไหลข้ามขอบพื้นที่ระดับเดียวกับยอดของมัน โค้งออกแล้วตกลงล่าง
  แบบ `wall` ไหลลงผนังถ้ำด้านหลังพื้นที่ระดับเดียวกับฐาน จากสูงไม่เกิน 4.4 ม. ตัวน้ำตกกว้างขึ้นที่ฐาน มีฟองบนน้ำและละอองขึ้นจากฐาน
  ความกว้างเป็น 1.4 เท่า (`ledge`) และ 1.8 เท่า (`wall`) ของที่ลอกจากคอนเซป
- **พื้นเก่าและพัง**: หินที่ยกเหนือน้ำ (ทางเดิน แท่น ฐานแท่นบูชา) พังตามแนวรอยต่อของแผ่นพื้นจริง ไม่ใช่รอยเว้าโค้งเรียบ
  `grotto-trace.py` เลือกจุดพังบนขอบที่ติดน้ำ (ราว 1 จุดต่อขอบ 170 พิกเซล ห่างกันอย่างน้อย 6 ม.) และหลุมทรุดกลางแท่นได้ห้องละหนึ่งหลุม
  แล้วถอดแผ่นพื้นทั้งแผ่นรอบจุดนั้นออกบนกริด 5 ซม. ตามผังแผ่นหินของลายพื้น (`flagstoneCourses()` ใน `textures.js`, พิมพ์ออกด้วย `scripts/grotto-paving.mjs`)
  แผ่นที่อยู่ไกลจากจุดพังบางแผ่นหักครึ่งตามแนวหยัก ขอบที่พังจึงเป็นขั้นตามรอยต่อ ไม่พังตรงที่ของวางอยู่ ตีนบันได หรือจุดที่จะตัดทางเดินขาดเป็นสองท่อน
  ทุกจุดที่พังได้ prop `rubble` (ไม่มีกันชน) ที่บอกแผ่นหินที่หลุดไป (`stones`: x, z, กว้าง, ลึก): `floors.js` วาดทุกแผ่นที่ร่วงลงน้ำ
  ลายบนหน้าแผ่นเป็นแผ่นเดิมของมัน ไถลออกไปทางที่ขอบหัน เอียงลง บางแผ่นยังพิงขอบโผล่พ้นน้ำ `props.js` วาดเศษหินเล็กรอบ ๆ
  ขอบตรงนั้นไม่มีหินขอบ หินขอบที่เหลือเก่า: หายไปบ้าง (13%) เอียงหรือจมลงข้างนอกบ้าง (17%) ที่เหลือเอียงนิด ๆ
  พื้นหินมีรอยสึก (`wornTexture`): คราบชื้น รอยร้าวเส้นเล็ก รอยบิ่นตื้น และตะไคร่ ราวหนึ่งรอยต่อ 45 ตร.ม. และหนึ่งรอยข้างทุกจุดที่พัง ไม่ทับของและไม่ล้นขอบ
- **แสง** อุ่นออกส้มเล็กน้อย (`look.hemi`, `look.sun`)
- **สีหินผนัง** เป็นหินเทาอ่อนแบบเกม (ดู "มาตรฐานเดียวกับเกม" ข้างล่าง) ความมืดสว่างของชั้นหินมาจากเงาซอกที่อบไว้ในโมเดล
- **ผนังถ้ำทุกห้อง**: โซนที่มี `walls` (ทุกห้องนอกจากถ้ำประตูมุก) ได้ผนังหินจาก `grotto-cave.py` เหมือนกัน แต่ขึ้นเฉพาะขอบที่ติดความมืด
  ส่วนขอบที่ลงไปหาน้ำหรือพื้นที่ต่ำกว่ายังเป็นขอบหินเตี้ยแบบเดิม ผนังด้านหลังสูงไม่เกิน 5 ม. ด้านที่หันหากล้องเตี้ย
  รูในพื้น (เกาะหินกลางห้อง) เป็นกองหินสูงไม่เกิน 2.4 ม. ไม่ใช่ผนังถ้ำ ผนังห้องเหล่านี้หยาบกว่าถ้ำทางเข้า (คอลัมน์ทุก 1.2 ม.) เพราะยาวรวมราว 1,600 ม.
  ขอบที่มีพื้นอีกชิ้นอยู่ถัดไปไม่เกิน 11 ม. (`divider`) เป็นสันหินเตี้ย ไม่บังทาง ก้อนหินหน้าผนังและปลายทางเดินเล็กและห่างกว่าเดิม
  หินขอบแบบสร้างในเกม (`rim.js`) ไม่วาดซ้ำตรงที่โมเดลมีผนังแล้ว
- ถ้าแก้ผังหรือย้ายประตูมุก ต้องรัน `grotto-trace.py` ก่อน แล้วรัน `grotto-cave.py` ใหม่ (ใช้เวลาราว 10 วินาที)
  เทสต์ใน `dungeon.test.js` จะล้มถ้าโมเดลถ้ำไม่ได้สร้างจากแผนที่ปัจจุบัน (เทียบค่า hash ใน extras ของไฟล์)
- โซนถัดไป: เปลี่ยนโซนนั้นเป็น `style: "cave"` (ใส่ `round` ถ้าขอบเป็นร่อง) แล้วรันสองสคริปต์ข้างบน จากนั้นปรับจนได้คุณภาพเท่าโซนนี้

## มาตรฐานเดียวกับเกม (เจ้าของ 29 ต.ค. 2026: "ปรับปรุงด้วยวิธีเดียวที่ทำในเกม ทางสายกลาง")

ผังและโมเดลยังเหมือนเดิม แต่ทาสีและทำบันไดด้วยวิธีเดียวกับฉากในเกม (`src/render/accepted-scenes/*.js`)
- **สีหินแบบเกม** (`src/render/grotto/game-paint.js`): พื้น ผนังหน้าผา ผนังถ้ำ ก้อนหิน และบันได ใช้ shader สามโทนแบบ `paint()` ของฉากในเกม
  แสงมาจากทิศแดดกับเงา (ไม่ใช่สีโคมไฟ) แต่ละโทนมีสีของมันเอง (เงาออกม่วงอ่อนแบบหินในเกม) สีเดิมของจุดยอด (น้ำตาล) ถูกดึงเข้าหาหินเทาอ่อนของเกม
  แต่ยังเก็บความมืดสว่างไว้ (เงาซอกที่อบไว้ รอยต่อ รอยสึก) ค่าทั้งหมดอยู่ใน `look.paint` ของข้อมูลดันเจี้ยน: `sun` `shade` `mid` `lit` `band`
  `sat` (เก็บสีเดิมไว้เท่าไร) `tint` (สีหิน) `gain` (ความสว่างแยกตามชนิดผิว: `rock` `cave` `cliffs` `stone-block`) `floor` (สีที่หน้าผาจางลงไปใต้ −2 ม.) และ `ink` (สีเส้นขอบ)
  น้ำ ทราย และพื้นใต้น้ำยังใช้สีของมันเอง
- **เส้นขอบหิน**: ก้อนหินของถ้ำและหินขอบมีเส้นขอบสีเดียวกับหินแบบก้อนหินในเกม
- **บันไดหินแบบเกม** (`stoneStairs` ของฉากในเกม): ทุกขั้นเป็นแถวหินตัดสีเทา กว้างราว 0.9 ม. วางขวางบันได รอยต่อสลับครึ่งก้อนทุกขั้น
  หน้าขั้นยื่นเป็นลูกตั้ง และมีหินแก้มสูง 0.45 ม. สองข้าง
- **แผ่นพื้นขนาดเท่าเกม**: ลายพื้นหนึ่งรอบกว้าง 6 ม. (`PAVING_TILE` ใน `textures.js`) แผ่นหินจึงกว้างราว 1 ม. ข้างตัวละคร
  จุดพังของพื้นยังตามรอยต่อแผ่นจริง เพราะ `grotto-paving.mjs` อ่านค่าเดียวกัน (รัน `grotto-trace.py` ใหม่ทุกครั้งที่เปลี่ยนค่านี้)
- น้ำตื้นและน้ำลึกเรืองน้อยลง ภาพไม่ฟ้าจ้า

### รอบสอง (เจ้าของ 29 ต.ค. 2026: ผนังถ้ำมีแบบของตัวเอง ลดแสง ให้แสงจากของเรืองชัดขึ้น จัดของที่วางมั่วให้เข้าที่)
- **ผนังถ้ำแบบของตัวเอง**: ผนังและก้อนหินของถ้ำไม่ใช่หินเทาอ่อนของเกม แต่เป็นหินถ้ำสีเทาเข้มอมม่วง (`look.paint.tints.rock`, `tints.cliffs`)
  พื้นปูยังเป็นหินอ่อนกว่า เหมือนคอนเซปที่ทางเดินสว่างกว่าผนัง
- **มืดลง แสงจากของเรืองชัดขึ้น**: แสงที่ทาไว้ของหินลดลงเหลือ `dim` (0.55) แสงรอบ ๆ ลดลง (`hemi`, `sun`)
  ไฟของแผนที่และไฟเล็กที่เดินตามตัวละครส่องหินรอบตัวมัน (`lamp`) วงแสงบนพื้นของปะการัง ผลึก และมุกเข้มขึ้นและกว้างขึ้น
  (`look.glowPool`: ความทึบ 0.42, ขนาด 1.35 เท่า) และ bloom ของจอแรงขึ้น (`post.glow` 1.0)
- **จัดของให้เข้าที่** (`grotto-trace.py`):
  - เสาและเสาหักยืนเรียงตามขอบหินของทางเดินและแท่น ห่างขอบราวหนึ่งก้าว ไม่ยืนกลางน้ำหรือกลางทาง
  - หีบ ถัง ลัง เทียน และเสาไม้ ชิดผนังห้อง อยู่หน้าแนวปะการังที่ตีนผนัง และหันเข้ากลางห้อง
  - ปากบันไดนับเป็นพื้น ของจึงไม่ไปขวางทางขึ้นลง

### ลานบอส (เจ้าของ 29 ต.ค. 2026: "ลานบอสทำให้พื้นที่เหมาะกับการสู้")
- เจ้าของ: "ขอพื้นเป็นวงกลมสมบูรณ์": แท่น (`dais`) เป็นวงกลมพอดี รัศมี 13 ม. (`circle.r` ในโซน `dais`) ตั้งกลางห้องบัลลังก์
  (จุดที่วงกลมใหญ่สุดในห้องอยู่) พื้นที่ที่ภาพวาดเป็นแท่นเดิมกลายเป็นน้ำตื้นของห้อง ฐานเสาที่เคยติดหลังแท่นเอาออก ขอบแท่นจึงกลมไม่มีติ่ง
- เจ้าของ: "อยากให้เดินบนน้ำได้ หินที่บังเอาออก" ห้องบัลลังก์ทั้งห้องจึงเป็นเวทีเดียว: แท่น (`dais`) ลดลงมาสูง 2.0 ม. เท่าทางเดิน
  ก้าวลงน้ำตื้น (พื้น 1.6) ได้ทุกด้าน ไม่มีบันไดแท่นแล้ว และหินที่ภาพวาดไว้ระหว่างแท่นกับน้ำและกลางห้องถูกปิดเป็นพื้น
  (`join: "dais"`, `joinClose` ในโซน `throne`) เหลือแต่ผนังถ้ำรอบห้อง ขอบหินขอบไม่วางระหว่างพื้นของเวที
- `grotto-trace.py` ส่วน `arena` ใน trace: พื้นที่เดินได้ของ `zones` (แท่นกับห้องบัลลังก์) รวมกันเป็นเวที หาวงกลมใหญ่สุดบนนั้น
  (ตอนนี้รัศมี 20.7 ม.) แล้วย้ายของทุกชิ้นในวงออกไปไว้ที่ขอบวง (ไม่ไปขวางหัวบันไดหรือบัลลังก์ในระยะ `entryClear`)
  วงกลางรัศมี 19.3 ม. (`clear`) จึงไม่มีอะไรบัง
- แท่นไข่มุกย้ายไปด้านหลังสุดของแท่น ตรงข้ามบันไดขึ้นห้อง เป็นบัลลังก์ (`thronePad` 3.2 ม. ถึงขอบแท่น) บอสยืนหน้าบัลลังก์ `bossAhead` 7.5 ม. หันหาบันได
  (ตัวและเปลือกของบอสตาม `propTypes.bossSnail` ไม่ชนแท่นไข่มุก)
- วงอักขระสึก ๆ บนพื้น (`runeCircle`, `ring` 6) บอกกลางเวที และไฟของห้องย้ายมาแขวนกลางเวที ส่องถึงขอบ
- ข้อมูลเวทีอยู่ที่ `inside.arena`: `at` กลางเวที, `r`, `clear` (รัศมีที่โล่ง), `boss`, `bossFacing`, `throne`, `entry` ให้บอสใช้ตอนทำต่อ
- เทสต์: วงกลางเป็นพื้นเวที (หินหรือน้ำตื้น) ทั้งหมดและเดินถึงทุกจุด แท่นต่างจากน้ำไม่เกินหนึ่งก้าว ไม่มีของบัง บอสยืนบนแท่นหันหาทางเข้า (`dungeon.test.js`)
- โมเดลถ้ำสร้างใหม่ด้วย `grotto-cave.py` (Blender 4.2 หรือ `bpy` 4.2.0 บน Python 3.11)

  - `surfaceAt` บอกพื้นใต้จุดนั้น

  - `linkAt`/`inspectAt` ใช้กับประตูและประตูลับ ส่วน `reachableFrom` ใช้ตรวจว่าเดินถึงทุกที่

  - `floors.js` วาดพื้นกับหน้าผาที่ไล่สีลงไปในความมืด บันไดเป็นแถวหินตัดแบบเกม
  - `game-paint.js` สีหินสามโทนแบบฉากในเกม และหินตัด (`stoneBlock`) ที่บันไดใช้
  - `water.js` วาดน้ำและน้ำตก (shader เดียว ค่าอยู่ใน uniform)
  - `rim.js` วาดเปลือกหินต่อเนื่องรอบทุกขอบที่ตกลงไปในความมืด (ด้านเหนือสูงเป็นผนัง ด้านกล้องต่ำ) พร้อมก้อนหินหลุดเป็นระยะ ยกเว้นโซน `cave`
  - `cave.js` โหลด `grotto-cave.glb` แล้ววางพื้น ผนัง และก้อนหินของโซน `cave` (วัสดุ cel แบบเดียว สีมาจากจุดยอด)
  - `kit.js` โหลด `grotto-kit.glb` ให้ `props.js` ใช้ (ซุ้มประตู หีบ ลัง เสา ปะการัง)

  - `glow.js` วาดแสงเรืองของปะการัง ผลึก หีบ และมุก ทั้งหมดใน draw call เดียว
  - `creatures.js` สร้างเปลือกหอยเกลียว (ตัวสร้างเดียวใช้ทั้งบอสและเปลือกเล็ก)
  - `index.js` ประกอบไฟ วงแสงบนพื้น (ในโซน `cave` ยกขึ้นเหนือแผ่นหินที่เอียง ไม่อย่างนั้นแสงจะตัดแผ่นเป็นเส้นตรง) และละอองลอย
