# ถ้ำมุกในเปลือกหอยยักษ์ (Pearlshell Grotto)

ดันเจี้ยนจากภาพคอนเซปของเจ้าของ (`docs/reference/shell-grotto-concept.jpg`) ตอนนี้สร้างเป็น**หน้าแยก**
(`dungeon.html`) ก่อน เมื่อเสร็จแล้วจะรวมเข้าเกม โดยมีทางเข้าลับในเปลือกหอยยักษ์บนชายหาด

## เปิดดู

- ในเครื่อง: `npm run dev` แล้วเปิด `/dungeon.html` · หลัง build: `dist/dungeon.html`
- ตัวเลือก URL: `?at=inside` เริ่มในถ้ำ, `?found=1` เปลือกหอยเปิดแล้ว, `?view=overview` เริ่มที่ภาพรวม, `?post=0` ปิดการเกรดสีจอ
- เดิน: ลากนิ้วทางซ้ายของจอ (จอยลอย) หรือ WASD / ลูกศร · ปุ่มม่วงขวาล่างขึ้นเมื่อมีสิ่งให้ทำ · **ภาพรวม** ดูทั้งแผนที่ · ＋/－ ซูม

## ทางเข้าลับ

บนหาดมีเปลือกหอยยักษ์ ปากถูกคราบเพรียงกับทรายอุดไว้ (มีประกายเล็ก ๆ ชวนให้สังเกต) เดินเข้าใกล้ (ไม่เกิน `inspectR`)
แล้วปุ่ม **ตรวจสอบเปลือกหอย** จะขึ้น เมื่อกด คราบจะร่วงออก ปากหอยเปิดเป็นช่องมุกลึก และประตู (`links[].secret`) จะใช้ได้
พอเดินเข้าปากหอยก็จะเข้าถ้ำ ส่วนในถ้ำ ประตูหินที่มีแสงมุกอยู่ในห้องแรกจะพากลับออกมาที่หาด

เกมจริงมี **หอยสังข์ร้อง (Singing Conch)** ที่หาดเปลือกหอยของ Azure Coast อยู่แล้ว
(`render/accepted-scenes/shell-beach.js`, `models/accepted-scenes/singing-conch.glb`) ตอนรวมเข้าเกม ให้ใช้หอยตัวนั้นเป็นทางเข้าลับแทนเปลือกหอยของหน้าตัวอย่าง
(ส่วน `outside` ของไฟล์ข้อมูลมีไว้ทดลองบนหน้านี้เท่านั้น)

## ผัง: ลอกจากภาพคอนเซปโดยตรง

ผังในถ้ำ**ไม่ได้กะเอง**แต่ลอกจากภาพ (`scripts/grotto-trace.py`)
- สคริปต์หาพื้นหิน (สีครีมอุ่น) กับน้ำ (สีฟ้าเขียว) ในภาพ แล้วล้างจุดรบกวน (เงาเสา ของประดับ)
- แบ่งภาพเป็นโซนตามความสูง แล้วเขียนขอบพื้นเป็นรูปหลายเหลี่ยม (มีรูสำหรับเกาะหิน) ลง `shell-grotto.json` ส่วน `inside`
- ค่าทุกอย่างของการลอกอยู่ใน `data/dungeons/shell-grotto-trace.json` เป็นพิกัดพิกเซลของภาพ ได้แก่ โซนและความสูง บันได ของประดับ (`face` คือจุดที่หันไปหา) น้ำตก ไฟ ชื่อพื้นที่ และพื้นที่ที่ภาพบังไว้ (`fill`)
- อัตราส่วน: 0.08 ม./พิกเซล ตามแนวนอน และ 0.1 ม./พิกเซล ตามแนวลึก (ภาพมองเฉียงลงมา)
- แก้ผังที่ไฟล์ trace แล้วรัน `python3 scripts/grotto-trace.py` (ต้องมี numpy และ opencv-python) ห้ามแก้ส่วน `inside` ตรง ๆ

| โซน | ความสูง (ม.) | ในภาพ |
|---|---|---|
| `west` ทางลาดปะการัง ทางเดินหลัก ซุ้มประตูผนึก | 0 | ทางคดซ้ายกลาง และทางเดินบนจากกลางไปขวา |
| `entrance` ถ้ำประตูมุก | 0 (โทนอุ่น) | ซ้ายล่าง |
| `hoard` ห้องสมบัติลับ | 1.2 | ซ้ายบน ลงบันไดมาที่ทางเดินหลัก |
| `pool` เกาะหัวใจปะการัง | หิน −0.5 / พื้นน้ำ −0.9 | กลาง มีบันไดลงจากทางเดิน |
| `temple` วิหารจมน้ำ | หิน −2.0 / พื้นน้ำ −2.4 | ขวาล่าง บันไดลงจากเกาะ |
| `throne` / `dais` บัลลังก์ | น้ำ 1.6 / หิน 2.0 / แท่น 2.8 | ขวาบน บันไดขึ้นจากทางเดิน |

## โค้ดและข้อมูล

- ข้อมูล: `data/dungeons/shell-grotto.json` มีกฎร่วม (`maxStep`, `maxSlope`, `heroRadius`, `propTypes`) และสองแผนที่ `inside` / `outside`
  พื้นแต่ละชิ้นมีความสูงคงที่: `poly` (ขอบที่ลอกจากภาพ มีรูได้), `circle`, `ellipse`, `path` และ `stairs` ที่เป็นทางลาด ชิ้นที่อยู่ท้ายรายการชนะ
  ส่วน `kind` คือ stone/sand/nacre/shallow ที่เดินได้ และ deep ที่เดินไม่ได้
- กฎ: `src/core/dungeon.js` (ไม่ใช้ three/DOM)
  - `surfaceAt` บอกพื้นใต้จุดนั้น
  - `standY` ให้ลำตัว (`heroRadius`) ยืนบนพื้นที่เดินได้ และก้าวต่างระดับได้ไม่เกิน `maxStep` ขอบระหว่างสองชั้นจึงเป็นกำแพง มีแต่บันไดที่เชื่อมชั้น
  - `move` เดินแบบไถลตามขอบและของกีดขวาง และแบ่งก้าวย่อยทีละ 0.25 ม. เฟรมยาวจึงข้ามขอบไม่ได้
  - `linkAt`/`inspectAt` ใช้กับประตูและประตูลับ ส่วน `reachableFrom` ใช้ตรวจว่าเดินถึงทุกที่
- วาด: `src/render/grotto/`
  - `floors.js` วาดพื้นกับหน้าผาที่ไล่สีลงไปในความมืด บันไดเป็นขั้นจริง
  - `water.js` วาดน้ำและน้ำตก (shader เดียว ค่าอยู่ใน uniform)
  - `rim.js` วาดเปลือกหินต่อเนื่องรอบทุกขอบที่ตกลงไปในความมืด (ด้านเหนือสูงเป็นผนัง ด้านกล้องต่ำ) พร้อมก้อนหินหลุดเป็นระยะ
  - `props.js` รวมของประดับแบบ merge ตามวัสดุ และปลูกปะการังกับผลึกตามขอบถ้ำ
  - `glow.js` วาดแสงเรืองของปะการัง ผลึก หีบ และมุก ทั้งหมดใน draw call เดียว
  - `creatures.js` สร้างเปลือกหอยเกลียว (ตัวสร้างเดียวใช้ทั้งเปลือกยักษ์ บอส และเปลือกเล็ก)
  - `index.js` ประกอบไฟ วงแสงบนพื้น และละอองลอย
- หน้า: `dungeon.html`, `src/dungeon/` (input, กล้องเกม 40°, ภาพรวม, ประตู, ระลอกน้ำเวลาลุย)

## ตรวจ

- `node --test tests/core/dungeon.test.js` ตรวจว่า:
  - เดินถึงทุกห้องและที่สูง
  - บันไดชันไม่เกินกำหนด และต่อกับพื้นทั้งสองปลาย
  - ขอบเป็นกำแพง แม้เฟรมยาวก็ข้ามไม่ได้
  - ของกีดขวางบังทาง ส่วนกลางซุ้มโค้งว่าง
  - ของทุกชิ้นวางบนพื้น
  - ประตูลับใช้ได้หลังตรวจเท่านั้น และทั้งสองประตูส่งไปลงพื้นที่เดินถึง
- `npm run build && node tests/browser/grotto.mjs` (`BROWSER=webkit` สำหรับ Safari, `CHROMIUM_EXECUTABLE` ถ้าต้องชี้ Chromium เอง)
  เดินผ่านทางเข้าลับจริง ถ่ายทุกห้องกับภาพรวมไว้ที่ `tests/browser/out/grotto/` และจะล้มถ้ามี error บนหน้า

## ยังไม่ทำ (รอบต่อไป)

- บอสและมอน: เจ้าของให้พักไว้ก่อน ตอนนี้บนแท่นบัลลังก์มีแค่ไข่มุกใหญ่
- รายละเอียดที่ภาพมีมากกว่า:
  - เสาและซุ้มหักที่หนาแน่นกว่านี้
  - น้ำตกตามผนังหลังทุกห้อง
  - หินขอบที่เป็นก้อนเล็กซ้อนกัน (ตอนนี้เป็นแผ่นเหลี่ยม)
- หีบที่เปิดได้ ปริศนาวงอักขระ/ซุ้มผนึก
- รวมเข้าเกม:
  - เป็นแผนที่ instance (เกมตอนนี้เป็นโลกพิกัดเดียว ต้องตัดสินใจว่าจะเพิ่มแบบ instance หรือวางไว้นอกขอบโลก)
  - เตรียมฉากหลังจอโหลดตามกฎสองโหมดโหลด
  - เก็บสถานะ "พบทางลับแล้ว" ใน save (ต้องมี migration)
