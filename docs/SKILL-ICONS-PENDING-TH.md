# สกิลที่ยังไม่มีรูป

เจ้าของขอไว้ (2026-10-26): สกิลใหม่ที่ยังไม่มีรูปให้เขียนกำกับไว้ จะได้เลือกใส่รูปง่าย

- ในเกม สกิลเหล่านี้แสดงเป็นวงกลมเส้นประ มีชื่อสกิลและคำว่า **"ยังไม่มีรูป"**
- รายการในโค้ดอยู่ที่ `src/ui/pending-art.js` และในข้อมูลสกิลมี `"iconPending": true`

## วิธีใส่รูป

1. เตรียม PNG ขนาด 512 x 512 พื้นโปร่งใส 2 ไฟล์ต่อสกิล ตามแบบสกิลเดิม
   - รูปสี่เหลี่ยม: `public/assets/icons/skill/<id>.png`
   - รูปกลมสำหรับจอสัมผัส: `public/assets/icons/skill-round/<id>.png`
2. ส่งรูปมาพร้อมบอกว่าเป็นสกิลไหน (ใช้ชื่อไทยหรือ `id` ในตารางก็ได้)
3. Claude จะลงทะเบียนรูปใน `src/ui/raster-icons.js` ลบ `iconPending` ออกจากสกิลนั้น และลบชื่อออกจากรายการนี้
