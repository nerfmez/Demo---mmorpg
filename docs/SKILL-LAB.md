# Skill Lab

หน้าทดลองเอฟเฟกต์สกิลโดยเฉพาะ โหลดแค่พื้นเรียบ ตัวละคร หุ่นเป้า และโค้ดเอฟเฟกต์จริง (`src/render/vfx.js`) ไม่โหลดแมพ เมือง มอน หรือ HUD จึงเปิดบน iPad ได้ในไม่กี่วินาที

**เปิดบน iPad:** `https://nerfmez.github.io/Demo---mmorpg/lab/lab.html`

มุมซ้ายบนบอกชื่อ branch และ commit ที่กำลังแสดงอยู่

## ใช้งาน

- **ใช้สกิล**: ร่ายใส่หุ่นเป้า **วนอัตโนมัติ**: ร่ายซ้ำทุก ~2 วินาที
- **⏸ / +1 เฟรม**: หยุดแล้วเดินทีละเฟรม (1/60 วินาที)
- **1× ½× ¼× ⅒×**: ดูแบบช้า
- **⚙ ตั้งค่า**: เลือกสกิล (★ = มีลุคใน `data/combat-fx.json` `skills`), ธาตุ, จำนวนลูก (ทดสอบแบบ Split), อาวุธ (ไม้เท้า/คทาจะรวมแสงที่ปลาย), พื้น (ทราย/หญ้า/มืด เหมือนพื้นในเรฟ), ระยะ และกล้อง (มุมเดียวกับในเกม)

## ใครแสดงอะไร

- push ไป branch `claude/vfx-*` → workflow **Skill Lab preview** build lab ของ branch นั้น → **Deploy to GitHub Pages** (รันจาก main) เผยแพร่ไว้ที่ `/lab/` ภายในไม่กี่นาที เกมหลักที่ root ยังเป็นของ main เสมอ
- push ไป main → `/lab/` กลับมาแสดงของ main
- ตอนนี้เล่นซ้ำได้เฉพาะสกิล `projectile` (ร่าย → ลอย → โดน) สกิลชนิดอื่นจะเปิดใช้เมื่อทำเอฟเฟกต์ของสกิลนั้น โดยเพิ่มการเล่นซ้ำ event ของมันใน `src/lab/lab.js`

## สำหรับ agent

- ทำและตรวจเอฟเฟกต์ใน lab ก่อน ไม่ต้องจับภาพทั้งเกม: `npm run build && node tests/browser/lab.mjs <skill>` ใช้เวลาประมาณ 10 วินาที และบันทึกเฟรม cast/travel/impact/fireball/smoke ไว้ใน `tests/browser/out/lab-<skill>-*.png`
- ส่งลิงก์ lab ให้เจ้าของเกมลองเอง แทนการอัดวิดีโอ ถ้าต้องส่งภาพเคลื่อนไหว ให้อัด GIF สั้นๆ จาก lab
- lab เป็นเครื่องมือดูเท่านั้น ไม่มีกฎเกมทำงาน ขนาดเอฟเฟกต์ที่ต้องตรงกับพื้นที่โดนจริงยังต้องตรวจในเกม
