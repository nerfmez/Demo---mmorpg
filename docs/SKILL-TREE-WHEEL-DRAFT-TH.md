สถานะ: **ร่างที่ 1** (2026-10-25) เจ้าของโอเคเบื้องต้น ยังไม่เปลี่ยนโครงต้นไม้ในเกม (ส่วนสเตตัสข้อ 9 ลงเกมแล้ว) · ภาพวงล้อแตะดูได้: https://claude.ai/artifact/BrEsX8tpXk1TyFzwkqDswb
อ้างอิง:
- การตัดสินใจของเจ้าของ: [`SKILL-PROGRESSION-PLAN-TH.md`](SKILL-PROGRESSION-PLAN-TH.md)
- งานวิจัย PoE/Undecember และแท็ก 6 หมวด: [`SKILL-TAXONOMY-RESEARCH-TH.md`](SKILL-TAXONOMY-RESEARCH-TH.md)

## 1. หลักที่ใช้

1. **ต้นไม้เดียว ทุกคนเริ่มกลางวง** (แบบ PoE) ทิศในวงล้อคือแนวการเล่น ไปทางไหนก็ค่อย ๆ เปลี่ยนแนว
2. **วงในคือโหนดทั่วไป** ใช้แต้มจ็อบ Job Lv 1–39 ลงได้ทุกภาค ลองหลายแนวได้
3. **วงนอกคืออาชีพ** แตกได้ตอน Job Lv 40 เลือกได้ 1 อาชีพ ผูกกับภาคเดียว
4. **ในอาชีพไล่จากต้น → กลาง → ปลาย** (คล้าย Moon → Star → Sun ของ Undecember) ทุกช่วงมีทางแยก 2–3 ทาง
5. **โหนด 3 ระดับ** (แบบ PoE):
   - โหนดเล็ก: เพิ่มตัวเลข
   - โหนดเด่น: มีชื่อ เป็นทางแยก
   - โหนดเปลี่ยนกฎ: เปลี่ยนวิธีเล่น
6. **โหนดเสริมอ้างถึงแท็ก** (หมวดวิธีส่ง ธาตุ ผลลัพธ์ กลไก) ไม่อ้างถึงสกิลรายตัว สกิลที่เพิ่มทีหลังจะได้ผลทันที

## 2. ภาพรวมวงล้อ

```
                         INT
              จอมเวทธาตุ · ผู้อัญเชิญ
                 /                \
       INT/STR                      DEX/INT
  นักบวช · นักดาบเวท            นักล่าพิษ · นักธนูธาตุ
          |          ( กลางวง )          |
          |       โหนดทั่วไป Job 1–39      |
       STR                              DEX
 ผู้คุ้มกันโล่ใหญ่ ·              มือธนูพลัง ·
 นักรบอาวุธหนัก                  มือธนูกระจาย
                 \                /
                      STR/DEX
               นักดาบเร็ว · ผู้ท้าดวล
```

**6 ภาค ภาคละ 2 อาชีพ รวม 12 อาชีพ**
- 4 อาชีพเดิมย้ายไปอยู่ในภาค:
  - แวนการ์ด → STR
  - เรนเจอร์ → DEX
  - อาร์คานิสต์ → INT
  - วอร์เดน → INT/STR
- **VIT กับ AGI ไม่มีภาคของตัวเอง:** VIT เป็นโหนดป้องกันทางฝั่ง STR และ INT/STR ส่วน AGI เป็นโหนดความเร็วและสกิลเคลื่อนที่ ทางฝั่ง DEX และ STR/DEX
- **วงในระหว่างภาคมีทางเชื่อม** ผู้เล่นเดินข้ามไปเก็บโหนดทั่วไปของภาคข้าง ๆ ได้ เช่น สายธนูเก็บโหนดคริฝั่ง STR/DEX

## 3. วงใน: โหนดทั่วไปของแต่ละภาค

ใช้ผลที่กฎเกมรองรับอยู่แล้ว (ค่าใน `effects` ของ `data/jobtree.json`)

| ภาค | ธีม | ตัวอย่างโหนด (ผลที่มีอยู่แล้ว) |
|---|---|---|
| STR | ประชิดหนัก ถึก | ดาเมจประชิด `meleeDamagePct`, HP `maxHpPct`, ป้องกัน `defense`, บล็อก `blockChancePct`, มุมฟัน `meleeArcAdd` |
| STR/DEX | ตีเร็ว คริ | โอกาสคริ `critChancePct`, แรงคริ `critMultPct`, ดาเมจโจมตี `attackDamagePct`, ดูดเลือด `leechPct` |
| DEX | ยิง ความเร็ว | ดาเมจยิง `projectileDamagePct`, ความเร็วลูกที่ยิง `projectileSpeedPct`, เจาะเกราะ `penetrationPct`, ความเร็ววิ่ง `moveSpeedPct` |
| DEX/INT | พิษ ธาตุบนลูกยิง | โอกาสพิษ `poisonChancePct`, ดาเมจต่อเนื่อง `dotDamagePct`, ดาเมจธาตุ `elementalDamagePct`, ชาร์จหลบ `extraMovementCharges` |
| INT | เวท วงกว้าง อัญเชิญ | ดาเมจเวท `spellDamagePct`, ร่ายเร็ว `castSpeedPct`, รัศมี `areaRadiusPct`, ดาเมจอัญเชิญ `summonDamagePct`, MP `maxMpPct` |
| INT/STR | ฮีล บาเรีย ควบคุม | ฮีล `healPct`, บาเรีย `barrierPct`, ระยะควบคุม `controlDurationPct`, ฟื้น HP `hpRegen`, ลดคูลดาวน์ `cooldownPct` |

กลางวงมีโหนดพื้นฐานที่ทุกคนใช้ได้: ดาเมจรวม `damagePct`, HP, MP, ฟื้นพลัง และโหนดหาของ (ทอง วัตถุดิบ อุปกรณ์)

## 4. วงนอก: 12 อาชีพ

แต่ละอาชีพมี:
- **โหนดเข้าอาชีพ:** โหนดเปลี่ยนกฎ 1 อัน ได้ตอนเลือกอาชีพ
- **สกิลเฉพาะสาย 2–3 ตัว**
- **ทางแยก 3 ช่วง**
- **โหนดปลายสาย:** เปลี่ยนกฎ + ปลดสกิลคูลดาวน์ประจำสาย
- **จุดอ่อน**

ตัวเลขทุกตัวเป็นข้อเสนอ

### ภาค STR

**1. ผู้คุ้มกัน (โล่ใหญ่ ถือสองมือ)** · ที่ของสายโล่ล้วนตามที่เจ้าของบอก
- โหนดเข้า: บล็อกสำเร็จแล้วได้บาเรียตามสัดส่วนของดาเมจที่กัน
- สกิล: กระแทกโล่ (ปรับให้ใช้กับโล่ใหญ่ได้) + **ใหม่:** ดันโล่พุ่งชน, ปักโล่ยั่วศัตรูรอบตัว
- ทางแยก:
  - ต้น: บล็อก / บาเรีย
  - กลาง: สะท้อนดาเมจ / ยั่วศัตรู
  - ปลาย: กำแพงเคลื่อนที่ / ปกป้องเพื่อน
- คูลดาวน์ปลายสาย: **ใหม่** ป้อมโล่ (ยืนนิ่ง กันดาเมจด้านหน้าทั้งหมดชั่วครู่)
- จุดอ่อน: ดาเมจต่ำ ช้า

**2. นักรบอาวุธหนัก** (ดาบใหญ่ ขวาน กระบอง) · แวนการ์ดเดิมส่วนใหญ่อยู่ที่นี่
- โหนดเข้า: ทุบพื้นโดนศัตรู 3 ตัวขึ้นไป ได้คลื่นกระแทกซ้ำ 1 ครั้ง
- สกิล: ผ่าแนวหน้า, ฟันเปิดเกราะ, ทุบมึน
- ทางแยก:
  - ต้น: วงกว้าง / แรงต่อเป้า
  - กลาง: ดูดเลือดตามจำนวนเป้า / มึนนานขึ้น
  - ปลาย: คำรามแรงขึ้น / ฟันเปิดเกราะทั้งวง
- คูลดาวน์ปลายสาย: เสียงคำรามศึก
- จุดอ่อน: ช้า ตีพลาดแล้วเจ็บ

### ภาค STR/DEX

**3. นักดาบเร็ว** (มีดสั้น ดาบ ถือสองข้าง)
- โหนดเข้า: คริแล้วสกิลถัดไปร่ายเร็วขึ้น
- สกิล: แทงจุดอ่อน + **ใหม่:** ฟันไขว้ (ถือสองข้าง) และพุ่งแทง
- ทางแยก:
  - ต้น: คริ / เลือดไหล
  - กลาง: ข้างหลังแรงขึ้น / หลบแล้วโต้
  - ปลาย: คริแรง / ดูดเลือดเมื่อคริ
- คูลดาวน์ปลายสาย: **ใหม่** พายุดาบ (ฟันรัวรอบเป้าเดียว)
- จุดอ่อน: ตัวบาง

**4. ผู้ท้าดวล** (ดาบ + โล่เล็ก)
- โหนดเข้า: ตั้งรับสำเร็จแล้วฟันถัดไปคริแน่นอน
- สกิล: ตั้งรับสวนกลับ + **ใหม่:** ปัดอาวุธ
- ทางแยก:
  - ต้น: บล็อก / สวนกลับแรงขึ้น
  - กลาง: ดวลเป้าเดียว / ยั่ว
  - ปลาย: สวนกลับเป็นวง / ฟื้น HP เมื่อสวน
- คูลดาวน์ปลายสาย: **ใหม่** ท้าดวล (ล็อกเป้า 1 ตัว ดาเมจกับมันเพิ่ม)
- จุดอ่อน: อ่อนเมื่อโดนรุม

### ภาค DEX

**5. มือธนูพลัง** · เรนเจอร์เดิม
- โหนดเข้า: ชาร์จเต็มแล้วลูกทะลุทุกตัว
- สกิล: ชาร์จยิงรุนแรง + **ใหม่:** ยิงเล็งจุดอ่อน
- ทางแยก:
  - ต้น: ทะลุ / แรงเป้าเดียว
  - กลาง: ชาร์จเร็ว / ยิงไกล
  - ปลาย: คริระยะไกล / ทำลายเกราะ
- คูลดาวน์ปลายสาย: **ใหม่** ศรสังหาร (ชาร์จนาน ยิงแรงมาก)
- จุดอ่อน: ช้าต่อฝูง

**6. มือธนูกระจาย**
- โหนดเข้า: ยิงแตกได้ลูกเพิ่ม 1 ลูกฟรี
- สกิล: ฝนลูกธนู + **ใหม่:** ยิงกระจายรูปพัด
- ทางแยก:
  - ต้น: จำนวนลูก / รัศมี
  - กลาง: ชะลอ / ผลักถอย
  - ปลาย: ฝนต่อเนื่อง / ลูกระเบิด
- คูลดาวน์ปลายสาย: **ใหม่** ห่าธนู (ฝนลูกธนูใหญ่ตามตัว)
- จุดอ่อน: แรงต่อเป้าเดียวต่ำ

### ภาค DEX/INT

**7. นักล่าพิษ** (ธนู มีดสั้น)
- โหนดเข้า: พิษซ้อนได้เกิน 5 ชั้น
- สกิล: คำสาปอ่อนแรง + **ใหม่:** กับดักพิษ (เวทพิษเป็นสกิลทั่วไป ใช้ร่วมได้)
- ทางแยก:
  - ต้น: ซ้อนพิษ / พิษนาน
  - กลาง: กับดัก / ระเบิดพิษเมื่อตาย
  - ปลาย: คำสาปกระจาย / วิ่งเร็วเมื่อศัตรูติดพิษ
- คูลดาวน์ปลายสาย: **ใหม่** หมอกพิษ
- จุดอ่อน: ดาเมจมาช้า

**8. นักธนูธาตุ** · สายที่ใช้ **สกิลผสานแบบธนู** เป็นแกน
- โหนดเข้า: ศรผสาน (ศรอัสนี ธนูพิษ ศรเพลิง ฯลฯ) ได้ผลธาตุแรงขึ้น
- สกิล: ลูกธนูพราน (ฐาน) + **ใหม่:** ศรธาตุสลับ
- ทางแยก:
  - ต้น: ไฟ / น้ำแข็ง / สายฟ้า
  - กลาง: ติดสถานะ / เด้งต่อ
  - ปลาย: ผสาน 2 ธาตุ
- คูลดาวน์ปลายสาย: **ใหม่** ศรพายุธาตุ
- จุดอ่อน: ต้องมีเวทที่เข้าคู่

### ภาค INT

**9. จอมเวทธาตุ** · อาร์คานิสต์เดิม
- โหนดเข้า: ติดสถานะธาตุแล้วศัตรูรับดาเมจธาตุอื่นเพิ่ม
- สกิล: ธารเพลิง, กำแพงผลึก
- ทางแยก:
  - ต้น: ไฟ / น้ำแข็ง / สายฟ้า
  - กลาง: ร่ายเร็ว / รัศมี
  - ปลาย: เจาะธาตุ / ระเบิดซ้ำ
- คูลดาวน์ปลายสาย: **ใหม่** อุกกาบาต
- จุดอ่อน: ตัวบาง MP หมดเร็ว

**10. ผู้อัญเชิญ**
- โหนดเข้า: เรียกสัตว์อัญเชิญได้เพิ่ม 1 ตัว
- สกิล: หมาป่าวิญญาณ, ผู้พิทักษ์ศิลา
- ทางแยก:
  - ต้น: ฝูงเล็ก / ตัวใหญ่ตัวเดียว
  - กลาง: สัตว์ถึก / สัตว์แรง
  - ปลาย: สัตว์ระเบิดเมื่อตาย / บัฟสัตว์
- คูลดาวน์ปลายสาย: **ใหม่** เรียกจ่าฝูง
- จุดอ่อน: ตัวเองอ่อน

### ภาค INT/STR

**11. นักบวช** · วอร์เดนเดิม
- โหนดเข้า: ฮีลเกินหลอดกลายเป็นบาเรีย
- สกิล: ชำระบาดแผล, วงจังหวะรบ
- ทางแยก:
  - ต้น: ฮีล / บาเรีย
  - กลาง: ออร่า / ชำระ
  - ปลาย: ฮีลทั้งวง / ฟื้นคนตาย (ถ้ามีเล่นหลายคน)
- คูลดาวน์ปลายสาย: **ใหม่** ระฆังศักดิ์สิทธิ์
- จุดอ่อน: ดาเมจต่ำ

**12. นักดาบเวท** · สายที่ใช้ **สกิลผสานแบบประชิด** เป็นแกน
- โหนดเข้า: สกิลผสานใช้ช่องม็อดน้อยลง 1 ช่อง
- สกิล: ฟันกวาด, ใบมีดหมุน (ฐาน) + **ใหม่:** ดาบธาตุ (ใส่ธาตุให้อาวุธชั่วครู่)
- ทางแยก:
  - ต้น: ธาตุบนอาวุธ / คลื่นดาบ
  - กลาง: ร่ายเร็ว / ดูด MP
  - ปลาย: ผสานแรงขึ้น / ผสานซ้ำ
- คูลดาวน์ปลายสาย: **ใหม่** ฟันเวทครึ่งฟ้า
- จุดอ่อน: ต้องการทั้ง STR และ INT

## 5. แต้มและจังหวะ

ใช้เพดานใหม่ตามแผน: จ็อบเต็มที่ 70 ได้แต้มเลเวลละ 1 รวม 70 แต้ม

| ช่วง | แต้ม | ลงที่ไหน |
|---|---|---|
| Job 1–39 | 39 | วงในทั่วไป ภาคไหนก็ได้ |
| Job 40 | เควสเปลี่ยนอาชีพ | โหนดเข้าอาชีพ (ไม่ใช้แต้ม) |
| Job 40–70 | 31 | อาชีพ: ต้น ~10 · กลาง ~10 · ปลาย ~11 (โหนดเปลี่ยนกฎปลายสายใช้หลายแต้ม) |

ตอนนี้ในเกม อาชีพปลดที่ Job Lv 5 (`progression.job.jobChoiceLevel`) และจ็อบเต็มที่ 40 ต้องปรับทั้งสองค่า

## 6. สกิล: มีอยู่แล้วกับต้องสร้างใหม่

- **มีอยู่แล้วและกลายเป็นสกิลเฉพาะสาย:** 16 ตัว (ตามรายการข้อ 4)
  - กระแทกโล่, ผ่าแนวหน้า, ฟันเปิดเกราะ, ทุบมึน, เสียงคำรามศึก
  - แทงจุดอ่อน, ตั้งรับสวนกลับ, ชาร์จยิงรุนแรง, ฝนลูกธนู
  - คำสาปอ่อนแรง, ธารเพลิง, กำแพงผลึก, หมาป่าวิญญาณ, ผู้พิทักษ์ศิลา
  - ชำระบาดแผล, วงจังหวะรบ
- **สกิลทั่วไป** (ไม่ผูกอาชีพ): ฟันกวาด, ใบมีดหมุน, ลูกธนูพราน, ลูกเวทพื้นฐาน, ลูกไฟ, สายฟ้าโซ่, เวทพิษ, หินปะทุ, ระเบิดน้ำแข็ง, โล่เวท, น้ำพุฟื้นฟู
- **ต้องสร้างใหม่:** ประมาณ 2 ตัวต่ออาชีพ (สกิลสาย 1 + คูลดาวน์ 1) รวมราว 20 ตัว พร้อมท่า เอฟเฟค ไอคอน และวิธีหา

ข้อเสนอ: สร้างทีละ 4 อาชีพ (ภาคละ 1 ก่อน) เช่น นักรบอาวุธหนัก, มือธนูพลัง, จอมเวทธาตุ, นักบวช เพราะใช้สกิลที่มีอยู่แล้วได้มากที่สุด

## 7. สิ่งที่ต้องเพิ่มในระบบ

1. **ข้อมูลต้นไม้:**
   - เงื่อนไข Job Level ต่อโหนด
   - โหนดประเภทเปลี่ยนกฎ (`keystone`)
   - โหนดที่ปลดสกิล
   - เลือกอาชีพได้อย่างเดียว
2. **กฎใหม่สำหรับโหนดเปลี่ยนกฎ:** ต้องเขียนโค้ดใน `src/core/` ทีละตัว พร้อมเทสต์ เพราะตอนนี้มีแต่โหนดเพิ่มตัวเลข
3. **ผลใหม่ที่ทางแยกต้องใช้:** ดาเมจแยกธาตุ, ดาเมจทุบพื้นหรือฟันเป้า, ระยะเวลา และค่าของสัตว์อัญเชิญ
4. **หน้าจอวงล้อ:** วางโหนดเป็นวงบน iPad ซูมและเลื่อนด้วยนิ้ว
5. **เควส:** เควสเปลี่ยนอาชีพ Job Lv 40
6. **อาวุธใหม่:** โล่ใหญ่ (ถือสองมือ) สำหรับผู้คุ้มกัน

## 8. คำถามถึงเจ้าของ

1. 12 อาชีพนี้โอเคไหม อยากเปลี่ยน ตัด หรือรวมอาชีพไหน
2. หลังเลือกอาชีพ ยังลงแต้มโหนดทั่วไปวงในได้อยู่ไหม (ข้อเสนอ: ได้ แต่แต้มมีจำกัด จึงต้องเลือก)
3. 4 อาชีพแรกที่จะสร้าง ใช้ตามข้อเสนอในข้อ 6 ไหม
4. เปลี่ยนอาชีพทีหลังได้ไหม (ข้อเสนอ: ได้ ใช้ทองมากกว่ารีเซ็ตปกติ)

## 9. สเตตัส: หลัก / รองของแต่ละอาชีพ (เจ้าของเห็นด้วย 2026-10-25)

STR / DEX / INT เป็นทิศของวงล้อ ส่วน VIT, AGI และ LUK เป็นค่าร่างกายที่ทุก build ใช้บ้าง แต่ละอาชีพมี:
- **สเตตัสหลัก:** ใช้อัปเกรดสกิลของสาย
- **สเตตัสรอง:** ใช้กับเงื่อนไขอุปกรณ์และโหนดของสาย

| อาชีพ | หลัก | รอง |
|---|---|---|
| ผู้คุ้มกัน (โล่ใหญ่) | VIT | STR |
| นักรบอาวุธหนัก | STR | VIT |
| นักดาบเร็ว | DEX | AGI |
| ผู้ท้าดวล | STR | AGI |
| มือธนูพลัง | DEX | STR |
| มือธนูกระจาย | DEX | AGI |
| นักล่าพิษ | DEX | INT |
| นักธนูธาตุ | DEX | INT |
| จอมเวทธาตุ | INT | AGI |
| ผู้อัญเชิญ | INT | VIT |
| นักบวช | INT | VIT |
| นักดาบเวท | INT | STR |

**ลงเกมแล้ว:**
- **LUK (โชค)** เป็นค่าที่ 6 เพิ่มโอกาสคริ +0.15% และดรอปอุปกรณ์ +0.1% ต่อแต้ม
- **DEX** เปลี่ยนจากเพิ่มโอกาสคริ เป็นเพิ่มแรงคริ +0.5% ต่อแต้ม ส่วนดาเมจยิงและพลังโจมตีคงเดิม
- สาย build คริจึงต้องใช้ทั้ง DEX และ LUK (เจ้าของเลือกแบบนี้)
- เซฟเก่าได้ LUK เท่าค่าเริ่มต้น (3)
- **AGI อัปเกรดสกิลเคลื่อนที่:** มี 5 ขั้น ใช้ผลึกทักษะกับทองเท่าสกิลต่อสู้ และต้องมี AGI ขั้นละ 5 / 7 / 9 / 11
  - ทุกขั้นคืนชาร์จเร็วขึ้น 6% และระยะไกลขึ้น 4%
  - ค่าอยู่ใน `progression.movementUpgrade`
  - อัปได้ที่หน้าอัปเลเวล แท็บ "สกิลเคลื่อนที่ (AGI)"
