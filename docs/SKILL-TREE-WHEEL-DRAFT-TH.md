## 1. หลักที่ใช้

1. **ต้นไม้เดียว ทุกคนเริ่มกลางวง** (แบบ PoE) ทิศในวงล้อคือแนวการเล่น ไปทางไหนก็ค่อย ๆ เปลี่ยนแนว
2. **วงในคือโหนดทั่วไป** ใช้แต้มจ็อบ Job Lv 1–39 ลงได้ทุกภาค ลองหลายแนวได้
3. **วงนอกคืออาชีพ** แตกได้ตอน Job Lv 40 เลือกได้ 1 อาชีพ ผูกกับภาคเดียว
4. **ในอาชีพไล่จากต้น → กลาง → ปลาย** (คล้าย Moon → Star → Sun ของ Undecember) ทุกช่วงมีทางแยก 2–3 ทาง
5. **โหนด 3 ระดับ** (แบบ PoE):
   - โหนดเล็ก: เพิ่มตัวเลข
   - โหนดเด่น: มีชื่อ เป็นทางแยก
   - โหนดเปลี่ยนกฎ: เปลี่ยนวิธีเล่น
6. **โหนดเสริมอ้างถึงแท็ก** (หมวดวิธีส่ง ธาตุ ผลลัพธ์ กลไก) ไม่อ้างถึงสกิลรายตัว สกิลที่เพิ่มทีหลังจะได้ผลทันที

## 2. ภาพรวมวงล้อ

```
                         INT
              จอมเวทธาตุ · ผู้อัญเชิญ
                 /                \
       INT/STR                      DEX/INT
  นักบวช · นักดาบเวท              ธนูแทคติค · ธนูเวท
          |          ( กลางวง )          |
          |       โหนดทั่วไป Job 1–39      |
       STR                              DEX
 ผู้คุ้มกันโล่ใหญ่ ·              จอมธนู ·
 นักรบอาวุธหนัก                  นายพราน
                 \                /
                      STR/DEX
                จอมมีด · ผู้ท้าดวล
```

**6 ภาค ภาคละ 2 อาชีพ รวม 12 อาชีพ**
- 4 อาชีพเดิมย้ายไปอยู่ในภาค:
  - แวนการ์ด → STR
  - เรนเจอร์ → DEX
  - อาร์คานิสต์ → INT
  - วอร์เดน → INT/STR
- **VIT กับ AGI ไม่มีภาคของตัวเอง:** VIT เป็นโหนดป้องกันทางฝั่ง STR และ INT/STR ส่วน AGI เป็นโหนดความเร็วและสกิลเคลื่อนที่ ทางฝั่ง DEX และ STR/DEX
- **ช่วยฟาร์มได้เฉพาะ 2 อาชีพ** (เจ้าของ 2026-10-25): นายพราน (ธนู) กับจอมมีดสายย่อยโจร (มีดสั้น) ไม่มีกิ่งฟาร์มให้ทุกคน ทั้งสองช่วยฟาร์มแต่ได้ของต่างกันและเล่นต่างกัน:
  - นายพราน ได้ **วัตถุดิบและชิ้นส่วนมอน** (ไว้คราฟต์) จากการล่า: ชำแหละ ตามรอยเหยื่อ คู่หูคาบของ
  - จอมมีด (สายย่อยโจร) ได้ **ทองและอุปกรณ์** จากการขโมยระหว่างสู้: ล้วงกระเป๋า ขโมยไอเทม ตาถึงของดี
  - กิ่งฟาร์มเดิมในต้นไม้ตอนนี้ (สายเรนเจอร์) จะย้ายไปอยู่ในสองอาชีพนี้ ส่วนออปชันดรอปบนอุปกรณ์ยังอยู่ (เป็นของ ไม่ใช่อาชีพ)
- **วงในระหว่างภาคมีทางเชื่อม** ผู้เล่นเดินข้ามไปเก็บโหนดทั่วไปของภาคข้าง ๆ ได้ เช่น สายธนูเก็บโหนดคริฝั่ง STR/DEX

## 3. วงใน: โหนดทั่วไปของแต่ละภาค

ใช้ผลที่กฎเกมรองรับอยู่แล้ว (ค่าใน `effects` ของ `data/jobtree.json`)

| ภาค | ธีม | ตัวอย่างโหนด (ผลที่มีอยู่แล้ว) |
|---|---|---|
| STR | ประชิดหนัก ถึก | ดาเมจประชิด `meleeDamagePct`, HP `maxHpPct`, ป้องกัน `defense`, บล็อก `blockChancePct`, มุมฟัน `meleeArcAdd` |
| STR/DEX | ตีเร็ว คริ | โอกาสคริ `critChancePct`, แรงคริ `critMultPct`, ดาเมจโจมตี `attackDamagePct`, ดูดเลือด `leechPct` |
| DEX | ยิง ความเร็ว | ดาเมจยิง `projectileDamagePct`, ความเร็วลูกที่ยิง `projectileSpeedPct`, เจาะเกราะ `penetrationPct`, ความเร็ววิ่ง `moveSpeedPct` |
| DEX/INT | พิษ ธาตุบนลูกยิง | โอกาสพิษ `poisonChancePct`, ดาเมจต่อเนื่อง `dotDamagePct`, ดาเมจธาตุ `elementalDamagePct`, ชาร์จหลบ `extraMovementCharges` |
| INT | เวท วงกว้าง อัญเชิญ | ดาเมจเวท `spellDamagePct`, ความเร็ว `hastePct`, รัศมี `areaRadiusPct`, ดาเมจอัญเชิญ `summonDamagePct`, MP `maxMpPct` |
| INT/STR | ฮีล บาเรีย ควบคุม | ฮีล `healPct`, บาเรีย `barrierPct`, ระยะควบคุม `controlDurationPct`, ฟื้น HP `hpRegen`, ความเร็ว `hastePct` |

กลางวงมีโหนดพื้นฐานที่ทุกคนใช้ได้: ดาเมจรวม `damagePct`, HP, MP, ฟื้นพลัง และโหนดหาของ (ทอง วัตถุดิบ อุปกรณ์)

## 3.5 กติกาโครงสาย (เจ้าของ 2026-10-25 · ใช้กับทุกอาชีพ)

0. **แต่ละสายย่อยบอกสเตตัสที่เน้น** และโหนดผ่านของสายเป็นค่าที่เข้ากับสเตตัสนั้น (เช่น ผู้คุ้มกันสายป้อมปราการเน้น VIT โหนดผ่านเป็น HP และป้องกัน)

1. **ทุกสายย่อยใช้แต้มพอ ๆ กัน** ไม่ว่าจะเลือกทางไหน ไปถึงปลายสายด้วยแต้มเท่ากัน
2. **แยกทางได้ภายในโหนดเดียวกัน** เช่น ผู้บดขยี้เลือกเน้นชาร์จ / ดีบัฟ / แรงสุด ใช้โหนดผ่านร่วมกัน ต่างกันแค่โหนดสำคัญที่เลือก และราคาเท่ากัน
3. **ทุกสายมีทั้งโหนดผ่านและโหนดสำคัญ**
   - **โหนดผ่าน:** ค่าเล็ก ๆ ที่เอื้อต่อสายนั้น เช่น ดาเมจวงกว้าง +% ในสายผู้กวาดล้าง
   - **โหนดสำคัญ:** ค่าที่ใหญ่ขึ้นหรือมีเงื่อนไข ที่ทำให้แนวเล่นของสายเด่นขึ้น มีทั้งโหนดสำคัญที่เข้าสาย และระหว่างทาง
4. **ต้นไม้คือการส่งเสริม** ไม่ให้สกิลกดใช้ใหม่ (สกิลเรียนแยก) และไม่เปลี่ยนพฤติกรรมของสกิล เช่น แยกลูก ทะลุ หรือเด้ง (นั่นคือหน้าที่ของม็อด) โหนดผ่านเป็นค่าตัวเลข ส่วน**โหนดสำคัญและปลายสายเป็นพาสซีฟที่เปลี่ยนวิธีเล่นได้** (เจ้าของ 2026-10-25) เช่น คู่หูคาบของ, ซื้อขายของจอมหลอกลวง, สัตว์ตายแทนของผู้นำวิญญาณ · แต่ไม่ต้องเป็นพาสซีฟทุกโหนด: โหนดสำคัญแบบง่ายที่ตรงกับสายก็ดีอยู่แล้ว เช่น สายเวท ใช้ MP ลดลง, วงกว้างขึ้น, ระยะเวลาต่อเนื่องนานขึ้น ใช้พาสซีฟเฉพาะจุดที่ทำให้สายนั้นเด่นจริง · บางแนวเล่นไม่ต้องแยกเป็นสายย่อยหรืออาชีพใหม่ ใช้ทางแยกโหนดให้เลือกอัปทางใดทางหนึ่งในสายเดิมได้ (ราคาเท่ากัน) เช่น ผู้บดขยี้ (ชาร์จ / ดีบัฟ / แรงสุด), จอมธนู (แรง / เร็ว / คริ / เจาะเกราะ), ไฟเตอร์ (คู่ปรับ / ผู้นำทัพ / ยิ่งสู้ยิ่งแกร่ง) (เจ้าของ 2026-10-26)

**แม่แบบต่ออาชีพ** (แต้มอาชีพ Job 40–70 = 31 แต้ม):

```
โหนดเข้าอาชีพ (ได้จากเควส ไม่ใช้แต้ม)
   │
ลำต้นร่วม 4 แต้ม: โหนดผ่าน 2 + โหนดสำคัญ 1 (2 แต้ม)
   │
   ├── สายย่อย A ─┐
   ├── สายย่อย B ─┼─ แต่ละสาย 18 แต้มถึงปลายสาย:
   └── สายย่อย C ─┘    ช่วงต้น / กลาง / ปลาย ช่วงละ โหนดผ่าน 3 (1 แต้ม) + โหนดสำคัญ 1 (2 แต้ม) = 5
                        แล้วปลายสาย 3 แต้ม
```

- ลำต้น 4 + สายย่อย 18 = 22 แต้ม เหลือราว 9 แต้มไว้แวะเก็บช่วงต้นของสายย่อยอื่น (เล่นผสม) หรือกลับไปลงวงใน
- โหนดสำคัญที่ให้เลือกหลายทาง (เช่น ชาร์จ / ดีบัฟ / แรงสุด) ราคาเท่ากันทุกทาง
- โหนดบังคับ (เช่น คู่หูคาบของของนายพราน) อยู่ในลำต้นร่วม จึงไม่ทำให้สายใดแพงกว่ากัน
- ตอนลงเกมจริงจะมีเทสต์ตรวจว่าทุกสายย่อยของทุกอาชีพใช้แต้มถึงปลายสายเท่ากัน

**ความเร็วและมานา (เจ้าของ 2026-10-27 · ใช้กับทุกอาชีพ)**
- ความเร็วมีค่าเดียว `hastePct` (ร่ายและคูลดาวน์เร็วขึ้นพร้อมกัน เพดาน 200 ได้ผลครึ่งเดียวหลัง 50 เหมือนดาเมจ %) ไม่มี "ความเร็วตี", "ความเร็วร่าย" หรือ "ลดคูลดาวน์เฉพาะสกิลกลุ่มใด" แยก (ยกเว้นค่าของสัตว์อัญเชิญ เช่น ความเร็วตีของสัตว์)
- **สายที่เน้นความเร็วต้องมีตัวช่วยมานาในตัว** (ได้ MP เมื่อตีโดน หรือ MP ที่ใช้ลดลง) เป็นโหนดผ่านหรือโหนดสำคัญของสายนั้นเอง ยิ่งตีถี่ยิ่งได้คืนถี่ ไม่ต้องแบ่งแต้มไปลงสายอื่นเพื่อให้ออกท่าได้เร็วตามที่ลง
- **เทสต์บาลานซ์ตอนลงเกมจริง:** จำลองสายเร็วเทียบสายแรงของอาชีพเดียวกันด้วยแต้มเท่ากัน ทั้งตอนฟาร์ม (พักฟื้นมานาระหว่างตัว) และตีบอสต่อเนื่อง 90 วินาที (นับมานาด้วย) ต้องห่างกันไม่เกินประมาณ 10% (`core/balance.js` `balanceAt` / `longFightDps`)
- ผลจำลองบนต้นไม้เก่า (2026-10-27): สายเร็วล้วนตอนฟาร์มเท่าสายดาเมจ (ดาบ ×1.86 / ×1.87) แต่ตีบอสมานาหมด (×1.52) แบ่งแต้มไปลงมานาก็ยังแพ้ราว 10% (ไม้เวทแพ้ 20% ขึ้นไป) จึงต้องมีกติกาข้อบนในวงล้อ

**สมดุลไม่ใช่แค่ดาเมจ และคำว่า "โกง" (เจ้าของ 2026-10-27)**
- **โดดเด่น** (ต้องมี): เก่งมากในหน้าที่ของตัวเอง แลกกับจุดอ่อนที่ชัด เช่น สายดาเมจ (ทั้งตีเร็วและตีแรง) บางกว่าสายถึกเสมอ
- **โกง** (ต้องไม่มี): ไร้จุดอ่อน คือเท่ากันหรือดีกว่าอีกบิลด์ทุกด้านด้วยทรัพยากรเท่ากัน หรือคุ้มเกินไปเมื่อเทียบผลลัพธ์กับทรัพยากรที่จ่าย (แต้ม มานา ช่องอุปกรณ์ ออปชัน)
- วัดเป็นโปรไฟล์หลายด้าน: ฆ่าเป้าเดียว · ฆ่าฝูง · ความอึด · ความยั่งยืน (มานา ฟื้นเลือด) · ความคล่อง · ช่วยทีม · ทรัพยากรที่ใช้
- กฎตรวจ: ไม่มีบิลด์ใดชนะอีกบิลด์ทุกด้านที่ทรัพยากรเท่ากัน · ทุกบิลด์มีจุดอ่อนอย่างน้อยหนึ่งด้านต่ำกว่าค่ากลางชัดเจน · ทุกสายนำในด้านที่เป็นหน้าที่ของตัวเอง · เทียบตัวเลขตรง ๆ เฉพาะสายหน้าที่เดียวกัน (เช่น สายเร็วกับสายแรงของอาชีพเดียวกัน ห่างไม่เกินราว 10%)
- การจำลองรวมเส้นทางโหนด อุปกรณ์ และออปชัน (ชุดเน้นตี / เน้นอึด / ผสม) แล้วค้นหาคู่ที่ทำให้บิลด์ไร้จุดอ่อน
- **ทำเป็นระบบในเกมแล้ว** (`src/core/build-rules.js`, ค่าใน `progression.balance.rules`, เทสต์ `tests/core/build-rules.test.js`): ต้นไม้ปัจจุบันผ่าน (ไม่มีบิลด์โกงหรือไร้จุดอ่อน) แต่พบว่าสายธาตุไม่เข้ากับดาบ สายเร็วของไม้เวทแพ้เพราะมานา และสายตีเป้าเดียวต่างกันเกิน 10% · วงล้อต้องผ่านกฎชุดนี้ก่อนลงเกม

## 4. วงนอก: 12 อาชีพ

**แยก 3 อย่างให้ชัด (เจ้าของ 2026-10-25):**
- **สกิล** คือสิ่งที่กดใช้ ได้มาแยก (เรียน/คราฟต์) ไม่ได้มาจากต้นไม้ อาชีพแค่กำหนดว่าใช้สกิลไหนได้
- **ม็อด** คือการเปลี่ยนพฤติกรรมของสกิล (แตก ทะลุ เด้ง เปลี่ยนธาตุ ระเบิด ฯลฯ)
- **สกิลทรี** คือการส่งเสริมด้วยค่าตัวเลข ทั้งโหนดผ่าน โหนดสำคัญ และปลายสาย เป็นค่าที่ทำให้แนวเล่นนั้นเก่งขึ้น โหนดสำคัญกับปลายสายเป็นค่าที่ใหญ่ขึ้น ค่าที่มีเงื่อนไข หรือพาสซีฟที่เปลี่ยนวิธีเล่น (ไม่ใช่สกิลกดใช้ และไม่เปลี่ยนพฤติกรรมสกิลแบบม็อด)

แต่ละอาชีพมี: วิธีเล่น · โหนดเข้า · ลำต้นร่วม · สายย่อย (เน้นสเตตัส / โหนดผ่าน / โหนดสำคัญ / ปลายสาย) · สกิลของอาชีพ · จุดอ่อน
ตัวเลขทุกตัวเป็นข้อเสนอ คิดจริงตอนลงเกมตามสมดุล

**1. ผู้คุ้มกัน** · โล่ใหญ่ถือสองมือ สายโล่ล้วน
- วิธีเล่น: ยืนหน้าทีม ดึงศัตรูมาที่ตัวเอง แล้วไม่ล้ม
- โหนดเข้า: โอกาสบล็อกด้านหน้า +% และบล็อกสำเร็จได้บาเรีย % ของดาเมจที่กัน
- ลำต้นร่วม: HP %, ระยะเวลายั่ว %
- **ป้อมปราการ** · เน้น VIT · ผ่าน: HP, ป้องกัน · สำคัญ: ป้องกัน +4% ต่อศัตรูรอบตัว 1 ตัว (สูงสุด 5 ตัว), บล็อกสำเร็จฟื้น HP 2%, **ร่างกายไม่ยอมแพ้** (เจ้าของ 2026-10-29; `hpRegenPct` +1.5, `potionHealPct` −50) ฟื้น HP 1.5% ของ HP สูงสุดต่อวิ แต่ยาเลือดฟื้นได้ครึ่งเดียว ยืนแลกได้นานโดยไม่พึ่งยา · ปลายสาย (พาสซีฟ): **ป้อมไม่ล้ม** มีศัตรูรอบตัวตั้งแต่ 3 ตัว รับดาเมจลดลง 20% และไม่โดนผลักหรือมึน
- **ผู้พิทักษ์** · เน้น VIT + INT · ผ่าน: HP, ป้องกัน, MP, ความเร็ว, เกราะเวท · สำคัญ: บาเรียที่ให้เพื่อน +20%, (พาสซีฟ) **รับแทน** ดาเมจที่เพื่อนในระยะ 6 เมตรโดน 25% ย้ายมาที่เรา (ลดด้วยค่าป้องกันของเรา) · ปลายสาย (พาสซีฟ): **ปราการรวมใจ** เพื่อนในระยะ 6 เมตรรับดาเมจลดลง 15% และไม่สะดุ้ง
- **โล่บุก** · เน้น VIT + STR · ผ่าน: HP, ป้องกัน, ดาเมจประชิด · สำคัญ: ดาเมจประชิด +1% ต่อป้องกัน 100, ระยะผลัก +30% · ปลายสาย (พาสซีฟ): **โล่สวน** บล็อกสำเร็จทำให้ศัตรูที่ตีมึน 0.5 วินาที (ศัตรูแต่ละตัว 6 วินาที) และเป้าที่ล้มหรือมึนรับดาเมจจากเรา +40%
- สกิลของอาชีพ (เรียนแยก): กระแทกโล่ (มีอยู่) · ใหม่: ยั่วยุ, ยืนหยัดทีม, ป้อมโล่, กำแพงแห่งศรัทธา, ทลายแนว
- จุดอ่อน: ช้า ดาเมจต่ำ (ยกเว้นโล่บุก)

**2. นักรบอาวุธหนัก** · ดาบใหญ่ ขวาน กระบอง แบบสองมือ · แวนการ์ดเดิมส่วนใหญ่อยู่ที่นี่
- วิธีเล่น: ช้าแต่ทุกทีหนัก เข้ากลางฝูงหรือทุบบอส
- โหนดเข้า: ดาเมจอาวุธสองมือ +% และโอกาสสะดุ้งระหว่างเงื้อลดลงมาก
- ลำต้นร่วม: ดาเมจประชิด %, HP %
- **ผู้กวาดล้าง (วงกว้าง)** · เน้น STR · ผ่าน: ดาเมจวงกว้าง, รัศมี · สำคัญ: ดาเมจ +5% ต่อศัตรูที่โดนในครั้งเดียว (สูงสุด 5 ตัว), (พาสซีฟ) **ดูดเลือดหมู่** ดูดเลือด 1% ต่อศัตรูที่โดน (สูงสุด 5%) · ปลายสาย (พาสซีฟ): **แรงส่ง** ฟาดวงกว้างฆ่าศัตรูได้ ทีถัดไปแรงขึ้น 40% และกว้างขึ้น 30% (ไม่ซ้อน)
- **ผู้บดขยี้ (เป้าเดียว)** · เน้น STR · ผ่าน: ดาเมจประชิด, แรงคริ · สำคัญ เลือก 1 ราคาเท่ากัน: **ชาร์จ** (ดาเมจตามเวลาเงื้อ สูงสุด +40%) / **ดีบัฟ** (มึนและล้มนานขึ้น 30% เป้าที่มึนรับดาเมจ +20%) / **แรงสุด** (ดาเมจต่อครั้ง +30% แลกความเร็ว −15) · สำคัญ (พาสซีฟ): **ทุบเกราะ** ตีโดนเป้าเดิม ลดป้องกันมัน 5% ต่อครั้ง (สูงสุด 5 ชั้น อยู่ 6 วินาที) · ปลายสาย: ดาเมจใส่บอสและเป้าเดียว +30%
- สกิลของอาชีพ: ผ่าแนวหน้า, ฟันเปิดเกราะ, ทุบมึน (มีอยู่) · ใหม่: คำรามศึก, กายเหล็ก, แผ่นดินแยก, งัดพสุธา
- จุดอ่อน: ช้า ฟาดพลาดโดนสวนแรง ตามศัตรูเร็วไม่ทัน

### ภาค STR/DEX

**3. จอมมีด** · มีดสั้นระยะประชิด ถือสองข้างได้ · เน้น STR, DEX, LUK
- วิธีเล่น: เข้าประชิด หาจังหวะ ตีจุดอ่อน
- โหนดเข้า: โอกาสคริ +% มาก เมื่อตีจากข้างหลัง
- ลำต้นร่วม: ความเร็ว %, โอกาสคริ
- **นักฆ่า** · เน้น DEX + LUK · ผ่าน: โอกาสคริ, แรงคริ · สำคัญ: ดาเมจจากข้างหลัง +25%, ดาเมจครั้งแรกหลังซ่อนตัว +40% · ปลายสาย (พาสซีฟ): **เงาตามตัว** ฆ่าศัตรูด้วยการแทงหลังหรือจากที่ซ่อน กลับเข้าซ่อนตัว 2 วินาที (ทุก 8 วินาที)
- **มีดคู่** · เน้น DEX + STR · ผ่าน: ความเร็ว, ดาเมจประชิด, ได้ MP เมื่อตีโดน · สำคัญ: โอกาสติดเลือดไหล 15%, ดาเมจเลือดไหลและพิษ +25%, **ว่องไวเหนือแรง** (`finesse`, เจ้าของ 2026-10-29) โจมตีประชิดคิดจาก DEX แทน STR (STR เหลือแค่ HP, DEX ไม่ให้พลังโจมตีของตัวเองซ้ำ) ให้สายคริตีเร็ว DEX/AGI ตีแรงพอ ๆ กับสาย STR แต่ HP น้อยกว่า คนสาย STR เอาไปไม่ได้ประโยชน์ · ปลายสาย (พาสซีฟ): **จังหวะไม่หยุด** ตีโดนต่อเนื่องได้ชั้นละ ดาเมจ +2% (สูงสุด 15 ชั้น หายถ้าไม่ได้ตี 2 วินาที) ชั้นเต็มแล้วความเร็ว +15
- **โจร (ช่วยฟาร์มทองและอุปกรณ์)** · เน้น DEX + LUK · ผ่าน: โอกาสหลบ, ทองที่ได้ · สำคัญ: **ล้วงกระเป๋า** (ตีโดนมีโอกาส % ได้ทอง) → **ขโมยไอเทม** (โอกาส % ได้อุปกรณ์จากเป้า) → **ตาถึงของดี** (อุปกรณ์ที่ดรอปมีโอกาสเกรดดีขึ้น) · ปลายสาย: **จอมหลอกลวง** ดาเมจและโอกาสขโมยใส่ศัตรูที่งงหรือโดนหลอกอยู่ +% มาก
  - โหนดของจอมหลอกลวง (อัปได้หลังถึงปลายสาย): ขายของได้ราคาดีขึ้น, ซื้อของถูกลง (เพดานประมาณ +20% / −20%)
  - กันสลับอาชีพเอากำไร: ราคาพิเศษใช้ได้เฉพาะของที่ได้มาตอนเป็นสายนี้ (ติดป้ายตอนได้) · ค่าสลับพรีเซ็ตแพงขึ้นตามเลเวล · ไม่มีระยะรอ ไม่มีเพดานรายวัน
- สกิลของอาชีพ: แทงจุดอ่อน (มีอยู่) · ใหม่: ซ่อนตัว, ฟันไขว้, ขโมย, ร่างแยกหลอก, แทงหลัง, พายุมีด
- จุดอ่อน: ตัวบาง ต้องหาจังหวะ

**4. ผู้ท้าดวล** · ดาบมือเดียว ถือโล่เล็กหรือดาบสองข้างได้
- วิธีเล่น: ยืนสู้ซึ่ง ๆ หน้า (ต่างจากนักฆ่าที่ซุ่มแทงหลัง)
- โหนดเข้า: ดาเมจใส่เป้าเดิม +% ซ้อนทีละขั้นยิ่งสู้นาน
- ลำต้นร่วม: ดาเมจประชิด %, ความเร็ว %
- **ไฟเตอร์ (สมดุล)** · เน้น STR + VIT · ผ่าน: HP, ป้องกัน, ดาเมจประชิด · สำคัญ: ฟื้น HP 1% ต่อวินาทีระหว่างสู้, รับดาเมจลดลง 8%, (พาสซีฟ) **ตั้งหลัก** HP ตกต่ำกว่าครึ่ง ได้บาเรีย 20% ของ HP สูงสุด และดาเมจ +20% 6 วินาที (ทุก 45 วินาที) · ปลายสาย เลือก 1 ทาง ราคาเท่ากัน (เจ้าของ 2026-10-26): **คู่ปรับ** สู้กับศัตรูตัวเดียว (ไม่มีตัวอื่นในระยะ 5 เมตร) ดาเมจ +20% และรับดาเมจลดลง 20% / **ผู้นำทัพ** บัฟที่ให้ตัวเองและเพื่อนแรงขึ้น 25% นานขึ้น 30% และระหว่างบัฟของเรายังอยู่ เพื่อนรอบตัวฟื้น HP 1% ต่อวินาที / **ยิ่งสู้ยิ่งแกร่ง** อยู่ในการต่อสู้ต่อเนื่อง ทุก 3 วินาทีได้ 1 ชั้น ดาเมจ +3% และป้องกัน +3% (สูงสุด 5 ชั้น หายเมื่อออกจากการต่อสู้)
- **เบอร์เซิร์กเกอร์ (บ้าพลัง)** · เน้น STR + AGI · ผ่าน: ดาเมจประชิด, ความเร็ว, ดูดเลือด, ได้ MP เมื่อตีโดน · สำคัญ: ดาเมจ +1% ต่อ HP ที่หายไป 2%, ความเร็ว +15 ตอน HP ต่ำกว่าครึ่ง, (พาสซีฟ) **เลือดแลกเลือด** ฆ่าศัตรูแล้วฟื้น HP 5% · ปลายสาย: ดาเมจ +30% และดูดเลือดเป็น 2 เท่า ตอน HP ต่ำกว่า 30%
- สกิลของอาชีพ (มีบัฟเน้นต่อสู้ให้ตัวเองและเพื่อน): ตั้งรับสวนกลับ (มีอยู่) · ใหม่: ปลุกใจ, ยืนหยัด, เลือดเดือด, คำรามคลั่ง, ขวัญนักสู้, คลั่ง
- จุดอ่อน: ไฟเตอร์ไม่มีดาเมจระเบิด · เบอร์เซิร์กเกอร์พลาดนิดเดียวอาจตาย

### ภาค DEX

สายธนูมี 4 อาชีพ: จอมธนู (DPS), นายพราน (คู่หู · ช่วยฟาร์ม), ธนูแทคติค (กับดัก), ธนูเวท (เวท) · ศรผสาน (ศรอัสนี ธนูพิษ ศรเพลิง) ใช้ได้กับนักธนูทุกสาย

**5. จอมธนู** · สาย DPS · เรนเจอร์เดิม
- วิธีเล่น: ยืนยิงทำดาเมจต่อเนื่อง
- โหนดเข้า: ดาเมจ +% เมื่อยิงโดนเป้าเดิมต่อเนื่อง (ซ้อนได้)
- ลำต้นร่วม: ดาเมจยิง %, ความเร็วลูกที่ยิง %
- **สายหลัก DPS** · เน้น DEX + LUK · ผ่าน: ดาเมจยิง, ความเร็ว · สำคัญ เลือกทางที่จะเน้น ราคาเท่ากัน: **แรง** (ดาเมจยิง +%) / **เร็ว** (ความเร็ว + และได้ MP เมื่อยิงโดน) / **คริ** (โอกาสและแรงคริ) / **เจาะเกราะ** (เจาะเกราะ %) · สำคัญ (พาสซีฟ): **ยืนนิ่ง** หยุดเดิน 1 วินาที ดาเมจยิง +15% จนกว่าจะเดิน (หลบด้วยสกิลเคลื่อนที่ไม่เสีย) · ปลายสาย (พาสซีฟ ตามทางที่เลือก): แรง **ลูกตัดสิน** ยิงโดนเป้าเดิมครบ 5 ครั้ง ลูกที่ 6 ดาเมจ 2 เท่า / เร็ว **ไม่ยั้งมือ** ยิงต่อเนื่องไม่หยุด 3 วินาที ความเร็วยิง +20% จนกว่าจะหยุด / คริ **ตาเหยี่ยว** คริแล้วคูลดาวน์สกิลยิงลด 0.3 วินาที / เจาะเกราะ **ทะลวงจุดอ่อน** ดาเมจ +1% ต่อป้องกันศัตรู 50 (สูงสุด +40%)
- สกิลของอาชีพ: ชาร์จยิงรุนแรง, ฝนลูกธนู (มีอยู่) · ใหม่: ยิงรัว, ศรสังหาร
- จุดอ่อน: ไม่มีกับดักหรือคู่หูช่วย

**6. นายพราน** · สายคู่หู · อาชีพธนูที่ช่วยฟาร์ม
- วิธีเล่น: สู้คู่กับสัตว์คู่หู
- โหนดเข้า: ดาเมจและ HP ของคู่หู +%
- ลำต้นร่วม: ดาเมจคู่หู % · **โหนดบังคับ: คู่หูคาบของ** คู่หูเก็บของที่ดรอปรอบตัวให้ (อาชีพเดียวที่ไม่ต้องเช่าสัตว์เก็บของ)
- **สายดาเมจ** · เน้น DEX + STR · ผ่าน: ดาเมจคู่หู, ดาเมจยิง · สำคัญ: ความเร็วตีของคู่หู +20%, ดาเมจใส่เป้าที่คู่หูตีอยู่ +15%, (พาสซีฟ) **คู่หูปกป้อง** ศัตรูตีเราระยะประชิด คู่หูกระโจนใส่และดึงมันไว้ 2 วินาที (ทุก 10 วินาที) · ปลายสาย: ดาเมจของเราและคู่หู +25% เมื่อตีเป้าเดียวกัน
- **สายฟาร์ม (วัตถุดิบและชิ้นส่วนมอน)** · เน้น DEX + STR · ผ่าน: โอกาสดรอปวัตถุดิบ · สำคัญ: **ชำแหละ** (มอนที่ล่าดรอปชิ้นส่วนเพิ่ม %) → **ตามรอยเหยื่อ** (เป้าที่ทำเครื่องหมายมีโอกาสดรอปชิ้นส่วนหายาก +%) → **คู่หูขุดหา** (คู่หูมีโอกาส % หาชิ้นส่วนเพิ่ม) · ปลายสาย: โอกาสชิ้นส่วนหายาก +% มาก
- สกิลของอาชีพ: ใหม่: เรียกคู่หู, สั่งคู่หูจู่โจม, ทำเครื่องหมายเหยื่อ, ฝูงล่า
- จุดอ่อน: ตัวเองตีเบา คู่หูตายแล้วอ่อนมาก

### ภาค DEX/INT

**7. ธนูแทคติค** · สายกับดัก
- วิธีเล่น: วางแผนก่อนสู้ วางกับดักแล้วล่อศัตรูเข้ามา
- โหนดเข้า: ดาเมจกับดัก +% ใส่ศัตรูที่โดนคุมหรือชะลออยู่
- ลำต้นร่วม: ดาเมจกับดัก %, ความเร็ว %
- **กับดักดาเมจ** · เน้น DEX + AGI · ผ่าน: ดาเมจกับดัก, รัศมีระเบิด · สำคัญ: ดาเมจ +8% ต่อกับดักที่ทำงานพร้อมกัน (สูงสุด 4), วางค้างได้ +1, (พาสซีฟ) **วางไว** วางกับดักแล้วคูลดาวน์กับดักอื่นลด 0.5 วินาที · ปลายสาย (พาสซีฟ): **กับดักซ้อน** ศัตรูโดนกับดัก 2 อันภายใน 3 วินาที อันที่สองแรงขึ้น 1.5 เท่า
- **กับดักคุม** · เน้น DEX + AGI · ผ่าน: ระยะเวลาคุม, ความเร็ว, MP ที่ใช้ลดลง · สำคัญ: ศัตรูที่ติดกับดักรับดาเมจจากทุกแหล่ง +15%, วิ่งเร็วขึ้น 15% ตอนมีศัตรูติดกับดัก · ปลายสาย (พาสซีฟ): **เขตกับดัก** ศัตรูในระยะ 5 เมตรรอบกับดักของเราเดินช้าลง 20%
- สกิลของอาชีพ: ใหม่: กับดักหนาม, กับดักตาข่าย, กับดักระเบิด, หุ่นล่อเป้า, ทุ่งกับดัก
- จุดอ่อน: ต้องวางแผน ศัตรูวิ่งเร็วหลุดง่าย

**8. ธนูเวท** · สายเวท (พิษเป็นธาตุหนึ่งในสายนี้)
- วิธีเล่น: ยิงศรผสานเวท เลือกธาตุหลักแล้วเล่นกับสถานะของธาตุนั้น
- โหนดเข้า: ดาเมจธาตุของศรผสาน +%
- ลำต้นร่วม: ดาเมจธาตุ %, MP %
- **สายย่อยเลือกธาตุ** · เน้น DEX + INT · เลือก 1 ราคาเท่ากัน: **ไฟ / น้ำแข็ง / สายฟ้า / พิษ** · ผ่าน: ดาเมจธาตุนั้น %, โอกาสติดสถานะของธาตุนั้น · สำคัญ: ความแรงและระยะเวลาสถานะ +25% (พิษ: ซ้อนได้ +2 ชั้น), MP ของศรผสานลดลง 15%, (พาสซีฟ) **ธาตุสะสม** ยิงโดนเป้าเดิมด้วยธาตุนั้น 5 ครั้ง ครั้งถัดไปติดสถานะแน่นอน · ปลายสาย (พาสซีฟ): **ดูดธาตุ** ยิงโดนศัตรูที่ติดสถานะธาตุของเรา ฟื้น MP 2% (ทุก 0.5 วินาที) และดาเมจ +20%
- สกิลของอาชีพ: ลูกไฟ, สายฟ้าโซ่, เวทพิษ (ทั่วไป ใช้ผสาน) · ใหม่: ศรธาตุสลับ, ศรพายุธาตุ
- จุดอ่อน: ต้องมีเวทที่เข้าคู่ ใช้ MP มาก

### ภาค INT

**9. จอมเวทธาตุ** · ไม้เท้า คทา · อาร์คานิสต์เดิม
- วิธีเล่น: ยืนระยะไกล ร่ายเวทแรงและวงกว้าง (ต่างจากธนูเวทที่ยิงเร็วด้วยธาตุบนลูกธนู)
- โหนดเข้า: ดาเมจเวท +% ใส่ศัตรูที่ติดสถานะธาตุ
- ลำต้นร่วม: ดาเมจเวท %, ความเร็ว % ชั่วครู่หลังฆ่าศัตรู, ดาเมจธาตุของเพื่อนรอบตัว +%
- **ไฟ** · เน้น INT · ผ่าน: ดาเมจไฟ, ดาเมจวงกว้าง · สำคัญ: โอกาสติดไฟ +15%, ไหม้แรงขึ้น 25% และนานขึ้น 1 วินาที, รัศมีเวทไฟ +15% · ปลายสาย (พาสซีฟ): **ไฟลาม** ศัตรูที่ตายตอนกำลังไหม้ ไฟลามไปศัตรูในระยะ 3 เมตร
- **น้ำแข็ง** · เน้น INT + VIT · ผ่าน: ดาเมจน้ำแข็ง, ระยะเวลาคุม · สำคัญ: ชะลอแรงขึ้น 15%, โอกาสแข็ง 10%, ระยะเวลาเวทต่อเนื่อง +20% · ปลายสาย (พาสซีฟ): **แตกเป็นเสี่ยง** ตีศัตรูที่แข็งอยู่ ดาเมจ +50% และน้ำแข็งแตก (หายแข็ง)
- **สายฟ้า** · เน้น INT + AGI · ผ่าน: ดาเมจสายฟ้า, ความเร็ว, MP ที่ใช้ลดลง · สำคัญ: โอกาสคริเวทสายฟ้า +10%, เด้งแล้วดาเมจลดน้อยลง, MP เวทสายฟ้าลดลง 15% · ปลายสาย (พาสซีฟ): **ช็อต** เวทสายฟ้าคริแล้วเป้าติดช็อต รับดาเมจจากทุกแหล่ง +15% 3 วินาที
- **ผสานธาตุ** (เจ้าของขอ 2026-10-26) · เน้น INT + AGI · สลับธาตุไปมาแล้วเกิดปฏิกิริยา · ผ่าน: ดาเมจธาตุทุกธาตุ, ความเร็ว, MP ที่ใช้ลดลง · สำคัญ (พาสซีฟ): **จังหวะธาตุ** ร่ายเวทคนละธาตุกับครั้งก่อน ได้ 1 ชั้น ดาเมจเวท +6% (สูงสุด 5 ชั้น อยู่ 5 วินาที ร่ายธาตุเดิมซ้ำไม่ได้ชั้น); **ปฏิกิริยาธาตุ** เวทธาตุที่สองโดนศัตรูที่ติดสถานะของธาตุแรก เกิดผลตามคู่ (ลำดับไหนก่อนก็ได้ ใช้สถานะเดิมหมดไป ศัตรูแต่ละตัวเกิดซ้ำได้ทุก 1.5 วินาที): ไฟ + น้ำแข็ง = **ไอระเบิด** ระเบิดวง 2.5 เมตร ดาเมจ 60% ของเวทที่จุด; ไฟ + สายฟ้า = **ระเบิดประจุ** ผลักศัตรูรอบเป้า 2.5 เมตร และมึน 0.5 วินาที; น้ำแข็ง + สายฟ้า = **ตัวนำเย็น** เป้ารับดาเมจจากทุกแหล่ง +20% 4 วินาที · ปลายสาย (พาสซีฟ): **ธาตุประลัย** ใช้ครบ ไฟ น้ำแข็ง สายฟ้า ใส่เป้าเดียวภายใน 6 วินาที เกิดระเบิดใหญ่รอบเป้า 3 เมตร ดาเมจ 200% ของพลังเวท (ศัตรูแต่ละตัวทุก 10 วินาที)
- สกิลของอาชีพ: ลูกไฟ, ระเบิดน้ำแข็ง, สายฟ้าโซ่ (ทั่วไป), ธารเพลิง, กำแพงผลึก (มีอยู่) · ใหม่: อุกกาบาต, พายุหิมะ, พายุฟ้าคะนอง
- จุดอ่อน: ตัวบาง MP หมดเร็ว ต้องรักษาระยะ

**10. ผู้อัญเชิญ** · คทา · เจ้าของเห็นด้วย 2026-10-25
- วิธีเล่น: เรียกสัตว์อัญเชิญหลายตัวมาสู้ ตัวเองยืนหลังแล้วร่ายช่วย (ต่างจากนายพราน: คู่หูตัวเดียวอยู่ตลอดและแรงตามพลังโจมตี ส่วนผู้อัญเชิญเรียกได้หลายตัว อยู่เป็นเวลา และแรงตามพลังเวท)
- โหนดเข้า: จำนวนสัตว์อัญเชิญสูงสุด +1
- ลำต้นร่วม: ดาเมจสัตว์อัญเชิญ %, ระยะเวลาที่สัตว์อยู่ %
- หมายเหตุ: เจ้าของจะเพิ่มไอเดียของอาชีพนี้มาเรื่อย ๆ
- **ฝูงวิญญาณ** · เน้น INT + AGI · ผ่าน: ความเร็วตีของสัตว์, ความเร็ว, MP ที่ใช้ลดลง · สำคัญ: จำนวนสัตว์สูงสุด +1, ดาเมจสัตว์ +% ต่อสัตว์ที่อยู่ 1 ตัว (มีเพดาน) · ปลายสาย: ความเร็วตีและดาเมจของสัตว์ +% มาก เมื่อมีสัตว์ตั้งแต่ 4 ตัว และ (พาสซีฟ) **ฝูงไม่สิ้น** สัตว์ตายหนึ่งตัว คูลดาวน์สกิลอัญเชิญลด 1 วินาที และได้ MP คืน 3%
- **อสูรใหญ่** · เน้น INT + VIT · ผ่าน: HP ของสัตว์, ป้องกันของสัตว์ · สำคัญ: สัตว์ดึงความสนใจศัตรูได้ดีขึ้น %, เรารับดาเมจลดลง % ตอนสัตว์ยังอยู่ · ปลายสาย: HP และดาเมจของสัตว์ +% มาก เมื่อมีสัตว์ตัวเดียว และ (พาสซีฟ) **อสูรคำราม** สัตว์ตัวใหญ่ยั่วศัตรูรอบตัว 4 เมตรทุก 8 วินาที นาน 2 วินาที
- **ผู้นำวิญญาณ** · เน้น INT · สายต่อสู้พร้อมกับสัตว์อัญเชิญ · ผ่าน: ดาเมจเวท, MP · สำคัญ: ดาเมจเวทของเรา +% ต่อสัตว์ที่อยู่ (มีเพดาน), **สัตว์รับดาเมจแทน** (ดาเมจที่เราโดน 20% แบ่งไปให้สัตว์ที่อยู่รอบตัว ไม่มีสัตว์ก็ไม่ได้ผล), ดาเมจของเราและสัตว์ +% เมื่อตีเป้าเดียวกัน · ปลายสาย (พาสซีฟ): **สัตว์ตายแทน** เมื่อเราจะโดนดาเมจถึงตาย สัตว์ที่อยู่ใกล้ที่สุดตายแทน เราเหลือ HP 1 และเป็นอมตะ 2 วินาที คูลดาวน์ 120 วินาที (ไม่มีสัตว์ก็ไม่ได้ผล)
- สกิลของอาชีพ: หมาป่าวิญญาณ, ผู้พิทักษ์ศิลา (มีอยู่) · ใหม่: เรียกฝูงภูต, เรียกจ่าฝูง, สั่งบุก, **สลับวิญญาณ** (สกิลเคลื่อนที่ ใส่ช่องสกิลหลบได้: สลับตำแหน่งกับสัตว์อัญเชิญในระยะ 10 เมตร ไม่โดนดาเมจระหว่างสลับ และฮีลสัตว์ตัวนั้น 15% ของ HP สูงสุด ชาร์จใหม่ 5 วินาที อัปเกรดด้วย AGI เหมือนสกิลเคลื่อนที่อื่น)
- จุดอ่อน: ตัวเองบาง ถ้าสัตว์ตายหรือหมดเวลาพร้อมกันจะอ่อนมาก ต้องรอคูลดาวน์เรียกใหม่

### ภาค INT/STR

**11. นักบวช** · ไม้เท้า หรือกระบองถือโล่ · วอร์เดนเดิม · เจ้าของเห็นด้วย 2026-10-25
- วิธีเล่น: ดูแลทีมให้รอด (เล่นคนเดียว ฮีล บาเรีย และเกราะเวทใช้กับตัวเองได้)

- ลำต้นร่วม: ความแรงฮีล %, MP %
- **ผู้เยียวยา (ฮีลและบัฟ)** · เน้น INT · ผ่าน: ความแรงฮีล, ระยะเวลาบัฟ, ฟื้น MP · สำคัญ: ฮีล +% ใส่คนที่ HP ต่ำ, บัฟที่เราให้แรงขึ้น % · สำคัญช่วงท้าย: **ชุบเร็ว** (คูลดาวน์สกิลชุบชีวิต −40%), **ชุบเต็ม** (ชุบแล้วได้ HP เต็มหลอด ปกติครึ่งหลอด) · ปลายสาย (พาสซีฟ): **ปาฏิหาริย์** เพื่อนหรือเราที่ HP ตกต่ำกว่า 20% ได้ฮีลทันที 30% ของ HP สูงสุด (คนละคูลดาวน์ 60 วินาที)

- **ผู้ปกป้อง (สายเกราะเวท ดูข้อ 10)** · เน้น INT + VIT · มีเกราะเวทหนาที่สุด แบ่งให้ทีม และใช้เกราะเป็นอาวุธ · ผ่าน: เกราะเวทสูงสุด %, ความเร็วฟื้นเกราะเวท %, รอฟื้นสั้นลง · สำคัญ (พาสซีฟ): **แบ่งเกราะ** เพื่อนในระยะ 6 เมตรได้เกราะเวท 25% ของเกราะสูงสุดของเรา ฟื้นตามเรา; **เกราะทันเวลา** ใช้โล่เวทไม่เกิน 0.5 วินาทีก่อนโดนตี เติมเกราะเวทของเป้าเต็มทันทีโดยไม่ต้องรอฟื้น; **ฟื้นไม่หยุด** โดนตีแล้วเกราะเวทยังฟื้นต่อที่ความเร็วครึ่งหนึ่ง · ปลายสาย (พาสซีฟ): **เกราะระเบิด** เกราะเวทของเราแตกแล้วระเบิดแสงทำดาเมจรอบตัวตามเกราะสูงสุด และให้บาเรียเพื่อนรอบตัว (คูลดาวน์ 10 วินาที)
  - ต่างจากผู้พิทักษ์ของผู้คุ้มกัน: ผู้พิทักษ์ใช้เลือดและค่าป้องกันรับดาเมจแทนเพื่อน ส่วนผู้ปกป้องให้ทุกคนมีเกราะเวทที่ฟื้นเอง
- สกิลของอาชีพ: ชำระบาดแผล, วงจังหวะรบ (มีอยู่) · ทั่วไปที่เข้ากัน: โล่เวท (แกนของผู้ปกป้อง), น้ำพุฟื้นฟู, คำสาปอ่อนแรง · ใหม่: ชุบชีวิต (HP ครึ่งหลอด คูลดาวน์ 180 วินาที), พรแห่งแสง (บัฟทีม), ระฆังศักดิ์สิทธิ์ (มึนรอบตัว), โซ่แสง (ตรึงศัตรู)

**12. นักดาบเวท** · อาวุธประชิด + เวท · เจ้าของเห็นด้วย 2026-10-25

- โหนดเข้า: ดาเมจของสกิลผสาน +%
- ลำต้นร่วม: ดาเมจสกิลผสาน %, MP ที่สกิลผสานใช้ลดลง %
- **วงกว้าง** · เน้น INT + STR · ผ่าน: รัศมีสกิลผสาน %, ดาเมจวงกว้าง · สำคัญ: ดาเมจสกิลผสาน +% ต่อศัตรูที่โดนในครั้งเดียว (มีเพดาน), (พาสซีฟ) สกิลผสานโดนศัตรูตั้งแต่ 5 ตัว ได้ MP คืน 30% · ปลายสาย (พาสซีฟ): **คลื่นผสาน** สกิลผสานโดนศัตรูตั้งแต่ 3 ตัว ได้ 1 ชั้น (ดาเมจสกิลผสาน +6% และรัศมี +4% ต่อชั้น สูงสุด 5 ชั้น อยู่ 4 วินาที ตีโดนอีกต่อเวลา) ยิ่งอยู่กลางฝูงนานยิ่งแรง
- **DPS (เป้าเดียว)** · เน้น INT + AGI (ความเร็ว ผสานได้ถี่ขึ้น) · ผ่าน: โอกาสคริสกิลผสาน, แรงคริ, ความเร็ว, MP ที่สกิลผสานใช้ลดลง · สำคัญ: ดาเมจสกิลผสาน +% ใส่เป้าที่ HP เกิน 70%, (พาสซีฟ) ใช้สกิลประชิดธรรมดาแล้ว สกิลผสานครั้งถัดไปคริแน่นอน (ทุก 4 วินาที) · ปลายสาย: ดาเมจสกิลผสานใส่บอสและเป้าเดียว +% มาก และเจาะเกราะ 30%
- **ดาเมจต่อเนื่อง** · เน้น INT + STR (ตีแรง สถานะแรงตาม) · ผ่าน: ดาเมจสถานะ (ไหม้ พิษ ช็อต), ระยะเวลาสถานะ · สำคัญ: โอกาสติดสถานะของสกิลผสาน +%, (พาสซีฟ) สถานะจากสกิลผสานซ้อนได้เพิ่ม 1 ชั้น · ปลายสาย (พาสซีฟ): **ธาตุประสาน** ศัตรูที่ติดสถานะจากเรา 2 แบบขึ้นไป รับดาเมจจากทุกสถานะ +% มาก
- สกิลของอาชีพ: ฟันกวาด, ใบมีดหมุน (ทั่วไป ใช้เป็นฐานผสาน) · ใหม่: ดาบธาตุ (เคลือบธาตุบนอาวุธ), คลื่นดาบเวท, ชักดาบพริบตา
- จุดอ่อน: ต้องลงทั้ง STR และ INT ใช้ MP มาก ไม่มีสายถึกในตัว (พึ่งเกราะเวทจากออปชันของ)

## 6. สกิล: มีอยู่แล้วกับต้องสร้างใหม่

สกิลได้มาแยกจากต้นไม้ (เรียน/คราฟต์) อาชีพกำหนดว่าใช้สกิลไหนได้ (รายการ "สกิลของอาชีพ" ในข้อ 4)

- **สกิลที่มีอยู่แล้วและกลายเป็นสกิลของอาชีพ:** กระแทกโล่, ผ่าแนวหน้า, ฟันเปิดเกราะ, ทุบมึน, แทงจุดอ่อน, ตั้งรับสวนกลับ, ชาร์จยิงรุนแรง, ฝนลูกธนู, ธารเพลิง, กำแพงผลึก, หมาป่าวิญญาณ, ผู้พิทักษ์ศิลา, ชำระบาดแผล, วงจังหวะรบ (เสียงคำรามศึกเดิมกลายเป็น "คำรามศึก" ของนักรบอาวุธหนัก)
- **สกิลทั่วไป** (ไม่ผูกอาชีพ): ฟันกวาด, ใบมีดหมุน, ลูกธนูพราน, ลูกเวทพื้นฐาน, ลูกไฟ, สายฟ้าโซ่, เวทพิษ, หินปะทุ, ระเบิดน้ำแข็ง, คำสาปอ่อนแรง, โล่เวท, น้ำพุฟื้นฟู
- **ต้องสร้างใหม่:** สกิลที่เขียนว่า "ใหม่" ในข้อ 4 พร้อมท่า เอฟเฟค ไอคอน และวิธีหา
- **ทำในเกมแล้ว ชุดที่ 1 (2026-10-26):** งัดพสุธา, แผ่นดินแยก, กายเหล็ก, ฟันไขว้, พายุมีด, ปลุกใจ, คำรามคลั่ง, ยืนหยัด, ยืนหยัดทีม, พรแห่งแสง, ยิงรัว, ศรสังหาร, อุกกาบาต, พายุหิมะ, พายุฟ้าคะนอง, ระฆังศักดิ์สิทธิ์, โซ่แสง, คลื่นดาบเวท · เรียนที่โต๊ะคราฟต์ด้วยวัตถุดิบจากมอน (ยังไม่ล็อกตามอาชีพ เพราะระบบอาชีพยังไม่ได้ทำ) · ยังไม่มีรูป (ดู `docs/SKILL-ICONS-PENDING-TH.md`) · เอฟเฟคและท่ายังเป็นแบบทั่วไปของประเภทสกิลนั้น
- **ทำในเกมแล้ว (2026-10-30, ท่าและเอฟเฟกต์ชั่วคราว):** ทลายแนว, ป้อมโล่, กำแพงแห่งศรัทธา (สกิลโล่ใหญ่)
- **ทำในเกมแล้ว ชุดที่ 2 กลุ่ม 1 (2026-10-30, บัฟ):** ยั่วยุ (ผู้คุ้มกัน), เลือดเดือด, ขวัญนักสู้, คลั่ง (ผู้ท้าดวล) · ใช้ท่าคำรามศึกและเอฟเฟคตะโกนบัฟแบบเดียวกับปลุกใจ
- **ชุดต่อไป (ต้องมีกลไกใหม่):** ซ่อนตัว, ขโมย, ร่างแยกหลอก, เรียกคู่หู, สั่งคู่หูจู่โจม, ทำเครื่องหมายเหยื่อ, ฝูงล่า, กับดักหนาม, กับดักตาข่าย, กับดักระเบิด, หุ่นล่อเป้า, ทุ่งกับดัก, ศรธาตุสลับ, ศรพายุธาตุ, เรียกฝูงภูต, เรียกจ่าฝูง, สั่งบุก, สลับวิญญาณ, ชุบชีวิต, ดาบธาตุ (แทงหลังและชักดาบพริบตาทำแล้ว)

ข้อเสนอ: สร้างทีละ 4 อาชีพ (ภาคละ 1 ก่อน) เช่น นักรบอาวุธหนัก, จอมธนู, จอมเวทธาตุ, นักบวช เพราะใช้สกิลที่มีอยู่แล้วได้มากที่สุด

## 7. สิ่งที่ต้องเพิ่มในระบบ

1. **ข้อมูลต้นไม้:**
   - เงื่อนไข Job Level ต่อโหนด
   - โหนดตัวเลขแบบมีเงื่อนไข (เช่น "เมื่อเลือดต่ำกว่า 50%", "กับเป้าที่ติดสถานะ")
   - โหนดพาสซีฟที่เปลี่ยนวิธีเล่น (โหนดสำคัญและปลายสาย)
   - รายการสกิลของอาชีพ (ใช้สกิลได้เมื่อเป็นอาชีพนั้น ตัวสกิลเรียนแยก)
   - เลือกอาชีพได้อย่างเดียว

3. **ผลใหม่ที่ทางแยกต้องใช้:** ดาเมจแยกธาตุ, ดาเมจทุบพื้นหรือฟันเป้า, ระยะเวลา และค่าของสัตว์อัญเชิญ · สถานะของสายฟ้า (ช็อต) และแข็ง สำหรับปฏิกิริยาธาตุ (ตอนนี้เกมมีแค่ ไหม้ เย็น พิษ เลือดไหล)
4. **หน้าจอวงล้อ:** วางโหนดเป็นวงบน iPad ซูมและเลื่อนด้วยนิ้ว
5. **เควส:** เควสเปลี่ยนอาชีพ Job Lv 40
6. **อาวุธใหม่:** โล่ใหญ่ (ถือสองมือ) สำหรับผู้คุ้มกัน

## 9. สเตตัส: หลัก / รองของแต่ละอาชีพ (เจ้าของเห็นด้วย 2026-10-25)

STR / DEX / INT เป็นทิศของวงล้อ ส่วน VIT, AGI และ LUK เป็นค่าร่างกายที่ทุก build ใช้บ้าง แต่ละอาชีพมี:
- **สเตตัสหลัก:** ใช้อัปเกรดสกิลของสาย
- **สเตตัสรอง:** ใช้กับเงื่อนไขอุปกรณ์และโหนดของสาย

| อาชีพ | หลัก | รอง |
|---|---|---|
| ผู้คุ้มกัน (โล่ใหญ่) | VIT | ตามสายย่อย: ป้อมปราการ VIT ล้วน · ผู้พิทักษ์ INT · โล่บุก STR |
| นักรบอาวุธหนัก | STR | VIT |
| จอมมีด (สายย่อย นักฆ่า / มีดคู่ / โจร) | DEX | STR (และ LUK ตามสายย่อย) |
| ผู้ท้าดวล | STR | AGI |
| จอมธนู (DPS) | DEX | LUK |
| นายพราน (คู่หู · ฟาร์มวัตถุดิบ) | DEX | STR (คู่หูคิดดาเมจจากพลังโจมตี ไม่ใช่พลังเวทแบบสัตว์อัญเชิญของสายเวท) |
| ธนูแทคติค (กับดัก) | DEX | AGI |
| ธนูเวท (เวท · ธาตุพิษอยู่ที่นี่) | DEX | INT |
| จอมเวทธาตุ | INT | AGI |
| ผู้อัญเชิญ | INT | VIT |
| นักบวช | INT | VIT |
| นักดาบเวท | INT | STR |

**ลงเกมแล้ว:**
- **LUK (โชค)** เป็นค่าที่ 6 เพิ่มโอกาสคริ +0.15% ต่อแต้ม (โอกาสดรอปไม่อยู่ที่ LUK: อยู่ในสกิลทรีและออปชันของ ตามที่เจ้าของตัดสิน)
- **DEX** เปลี่ยนจากเพิ่มโอกาสคริ เป็นเพิ่มแรงคริ +0.5% ต่อแต้ม ส่วนดาเมจยิงและพลังโจมตีคงเดิม
- สาย build คริจึงต้องใช้ทั้ง DEX และ LUK (เจ้าของเลือกแบบนี้)
- เซฟเก่าได้ LUK เท่าค่าเริ่มต้น (3)
- **AGI อัปเกรดสกิลเคลื่อนที่:** มี 5 ขั้น ใช้ผลึกทักษะกับทองเท่าสกิลต่อสู้ และต้องมี AGI ขั้นละ 5 / 7 / 9 / 11
  - ทุกขั้นคืนชาร์จเร็วขึ้น 6% และระยะไกลขึ้น 4%
  - ค่าอยู่ใน `progression.movementUpgrade`
  - อัปได้ที่หน้าอัปเลเวล แท็บ "สกิลเคลื่อนที่ (AGI)"

## 10. เกราะเวท (ระบบใหม่ เจ้าของเห็นด้วย 2026-10-25 · ทำในเกมแล้ว)

- หลอดสีขาวซ้อนบนหลอดเลือด โดนตีหักเกราะเวทก่อน หมดแล้วค่อยหักเลือด
- ไม่โดนตี 3 วินาที ฟื้นวินาทีละ 20% ของเกราะสูงสุด (โดนตีบ่อยจะไม่ได้ฟื้น)
- ต่างจากบาเรีย: บาเรียมาจากสกิล อยู่ชั่วคราวแล้วหาย ส่วนเกราะเวทติดตัวและฟื้นเอง
- ได้จาก: ออปชันของ เกราะเวท +50–160 ที่เลเวลของ 1 (โตตามเลเวลของเหมือนออปชันค่าดิบอื่น) และเกราะเวท +5–13% บนของสายเวท: ผ้าคลุมพายุ, เสื้อเดินทาง, ฮู้ดสปอร์, มงกุฎขนนก, จี้ภูตไฟ, จี้ไข่มุกทะเล, โล่กระดองปู · INT แต้มละ +8 (ก้อนหลักมาจากของ)
- คำว่า "บาเรีย" ใช้กับเกราะชั่วคราวจากสกิล (เดิมบางที่เรียกเกราะเวท เปลี่ยนชื่อแล้ว)
- สายที่เด่นเรื่องนี้: นักบวช ผู้ปกป้อง · ผู้คุ้มกัน ผู้พิทักษ์ได้โหนดผ่านเกราะเวทบ้าง · สายเวทอื่นใช้ผ่านออปชันของ
- เซฟไม่ต้องย้ายข้อมูล: เกราะเวทคำนวณจากสเตตัสกับของ เริ่มเต็มทุกครั้งที่เข้าเกม
- ในเกม: กฎใน `src/core/game-simulation.js` (`drainShield`, ฟื้นใน `updatePlayer`), ตัวเลขใน `data/progression.json combat.spellShield`, เทสต์ `tests/core/spell-shield.test.js`, หลอดขาวเหนือหลอด HP (ซ่อนเมื่อไม่มีเกราะเวท), ตัวเลขลอย "(ที่เกราะรับ)" และ "เกราะเวทแตก!"
