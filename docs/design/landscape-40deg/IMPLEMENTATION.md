# Landscape implementation

The approved concepts and coordinate plan remain in this directory. Runtime implementation and actual game review are on `feat/layered-landscape-40deg-20261021`; see [screenshots, evidence and limits](../../review/landscape-40deg/README.md). This is ready for owner review, not merged or live.

The owner-selected 40° camera from PR137 is included without its optional cel/frieren experiments. All 13 authored bands now use real terrain relief, upper planting, collidable outcrops and broken ruin masonry. Existing roads, services, water, city paving and shared seam bands remain protected. A3 is moved to the lower headland flank (`147,-76` through `201,-66`) because the concept centreline was entirely masked by the seam and shrine. Runtime data is authoritative for that refinement.

Core passed 593/593; production build and focused Chromium touch/capture passed. The original city/landmark scatter regression fixtures isolate their original authoring pass, while the new landscape tests independently check preservation outside the new footprints. New cliff geometry uses the single native heightfield surface and its existing rock paint. Region-owned outcrops, roots and walls are merged in bounded cells. Layout exports include the new records; no save schema/layout reset is introduced.

Capture: `npm run build && node tests/browser/landscape.mjs`. Set `BROWSER=webkit` for WebKit; `CHROMIUM_EXECUTABLE` and `CHROMIUM_EXTRA_ARGS` support an installed CI browser. Output defaults to `tests/browser/out/landscape/`. `LANDSCAPE_LOCATIONS=beach,forest,ruins` restricts iterative views, `LANDSCAPE_CAPTURE_ONLY=1` skips interaction/device sizes, and `LANDSCAPE_ROOT` can serve a separate camera-only baseline build. Draws are held between screenshots while the real frame/input loop remains active; counters include one complete original render.
