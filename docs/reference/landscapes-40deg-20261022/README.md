# ภาพต้นแบบภูมิทัศน์ — มุมกล้อง 40°

ภาพฉบับล่าสุด 19 โซน สร้างจากแนวภาพอ้างอิงชุดเดิมสำหรับออกแบบฉาก MMORPG เป้าหมายคือมุมกล้อง ARPG ประมาณ 40° มีชั้นภูมิประเทศ ต้นไม้และสิ่งปลูกสร้างสูงตามขอบฉาก พร้อมทางเดินและลานต่อสู้ที่อ่านง่าย

เก็บ PNG ต้นฉบับโดยไม่ย่อหรือบีบอัดเพิ่มเติม ภาพเหล่านี้เป็น concept art สำหรับอ้างอิงการสร้างฉาก ยังไม่ได้เชื่อมเข้าระบบเรนเดอร์ของเกม

## ฉบับที่เลือกเก็บ

- เมืองท่า: ประภาคารอยู่ฝั่งตะวันตก และอู่เรืออยู่ฝั่งตะวันออก
- ป่าโปร่งริมฝั่ง สวนริมทาง และเนินหลังเมือง: เลือกฉบับที่เห็นหลังคาหอพราน หลังคาศาลา และใบพัดกังหันครบ
- ไม่รวมภาพทดลองที่ถูกแทนด้วยฉบับแก้แล้ว

รายละเอียดขนาดไฟล์และค่า Git blob SHA อยู่ใน [manifest.json](manifest.json) และบันทึกการตรวจภาพอยู่ใน [REVIEW.md](REVIEW.md)
