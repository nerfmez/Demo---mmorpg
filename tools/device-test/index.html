ตั้งค่าชุดทดสอบ

ใช้ค่าเดียวกันทั้ง 6 รอบ อย่าเปิด A กับ B ค้างพร้อมกัน ปิดโหมดประหยัดพลังงานตามปกติและให้เครื่องพักเมื่อร้อน อย่าถือว่า browser ใหม่ล้าง cache ของระบบแล้ว

เปิดผ่านเว็บเซิร์ฟเวอร์ทดสอบคนละ origin กับเกมหลัก บน PC ใช้ serve.py; iPad ใช้ URL จาก PC ใน Wi-Fi เดียวกัน หรือโฮสต์ทดสอบแยกที่ได้รับอนุญาต

ในแต่ละรอบ

ตัววัดเริ่มเมื่อเปิดเกม กดปุ่ม วัดผล ด้านบนเพื่อกำกับช่วง: เปิดเกม → เข้าหาขอบแมพ → ข้ามไปกลับ 6 รอบ → ออกห่างแล้วกลับ → กลับตัวขณะโหลด → ยืนนิ่งหลังโหลด 10 วินาที

กด จบรอบและสรุปผล แล้ว บันทึก JSON หรือ แชร์ไฟล์ ก่อนกลับมาเลือกรอบถัดไป ภาพฉากจะจับได้เฉพาะหลัง imported-ready; ภาพเป็น canvas ไม่รวม HUD

ไม่ได้ย้ายตัวละคร ลบมอนสเตอร์ หรือหยุดเกมให้เอง ช่วงเปิดเมนูและภาพถูกกำกับในข้อมูลดิบ จำนวน texture/geometry ไม่ใช่หน่วยความจำ GPU; ไม่มี API จะส่งออก null

การเปิดบน PC / iPad

แตก ZIP แล้วรัน python3 serve.py (Windows ใช้ py -3 serve.py) จากโฟลเดอร์ชุดนี้ เปิด http://127.0.0.1:8765/

สำหรับ iPad ให้ PC รัน python3 serve.py --lan แล้วเปิด http://IP-ของ-PC:8765/ บน Safari ใน Wi-Fi ที่ไว้ใจได้ โปรแกรมพิมพ์ URL ให้ ไม่มีการแก้ firewall อัตโนมัติ หากไม่มี PC ต้องนำไฟล์ไปไว้บนเว็บทดสอบแยกก่อน — เปิด ZIP ใน Files แล้วเล่นโดยตรงไม่ได้

ผลตัวอย่างหรือ self-test ของหน้าเว็บไม่ใช่ผลประสิทธิภาพของอุปกรณ์จริง ค่าของหน้าเกมมี overhead จาก instrumentation เหมือนกันทั้ง A/B และไม่รับรอง 60 FPS จนกว่าจะวัด
